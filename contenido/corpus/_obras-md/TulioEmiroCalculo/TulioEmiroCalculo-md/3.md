# 1.9. PROBLEMAS

## 1.9. Problemas que involucran límites y continuidad

### PROBLEMA 1.1.
Demostrar el corolario (1.2.1, pág. 16).

**Solución.** Procedemos por contradicción.

Supongamos que el límite
$$\lim_{x\rightarrow x_{0}}\frac{f(x)}{g(x)}=A\in\mathbb{R}$$
existe.

Por hipótesis, $\lim_{x\rightarrow x_{0}}f(x)=L\ne0$ y $\lim_{x\rightarrow x_{0}}g(x)=0$.

Entonces:
$$L = \lim_{x\rightarrow x_{0}}f(x) = \lim_{x\rightarrow x_{0}}\left[\frac{f(x)g(x)}{g(x)}\right] = \lim_{x\rightarrow x_{0}}\left[\frac{f(x)}{g(x)}\right] g(x)$$
$$= \left[\lim_{x\rightarrow x_{0}}\frac{f(x)}{g(x)}\right]\left[\lim_{x\rightarrow x_{0}}g(x)\right] = A(0) = 0$$

lo cual es una contradicción a la hipótesis ($L\ne0$). Esto se presentó al suponer que el límite $\lim_{x\rightarrow x_{0}}\frac{f(x)}{g(x)}$ existe.

Por tanto el corolario queda demostrado. $\blacksquare$

### PROBLEMA 1.2.
Probar que $\lim_{x\rightarrow2}\frac{x-4}{(x+1)(x-3)}=\frac{2}{3}$.

**Solución.** La función $f(x)=\frac{x-4}{(x+1)(x-3)}$ está definida en el conjunto: $X=\mathbb{R}-\{-1,3\}$.

Sea $\epsilon>0$; encontramos $\delta>0$ tal que
$$(\forall x\in X): x\in B_{\delta}(2) \Rightarrow \frac{x-4}{(x+1)(x-3)}\in B_{\epsilon}\left(\frac{2}{3}\right)$$

En forma equivalente, encontramos $\delta>0$ tal que
$$(\forall x\in X): |x-2|<\delta \Rightarrow \left|\frac{x-4}{(x+1)(x-3)}-\frac{2}{3}\right|<\epsilon$$

Es fácil ver que:
$$\left|\frac{x-4}{(x+1)(x-3)}-\frac{2}{3}\right| = \frac{1}{3}\left|\frac{(x-2)(2x-3)}{(x+1)(x-3)}\right| = \frac{|x-2||2x-3|}{3|x+1||x-3|}$$

Teniendo en cuenta: el punto de acumulación $x_{0}=2$, el conjunto de definición de la función y la condición $x\in B_{\delta}(2)$ para todo $x\in X$, podemos asumir que $0<\delta<\frac{1}{2}$.

Luego:
- $|x-2|<\delta<\frac{1}{2} \Rightarrow |x-2|<\frac{1}{2} \iff -\frac{1}{2}<x-2<\frac{1}{2} \iff \frac{3}{2}<x<\frac{5}{2}$.
- $\frac{3}{2}<x<\frac{5}{2} \iff 3<2x<5 \iff 0<2x-3<2 \Rightarrow |2x-3|<2$.
- $\frac{3}{2}<x<\frac{5}{2} \iff \frac{5}{2}<x+1<\frac{7}{2} \Rightarrow \frac{2}{7}<\frac{1}{x+1}<\frac{2}{5} \Rightarrow \left|\frac{1}{x+1}\right|<\frac{2}{5}$.
- $\frac{3}{2}<x<\frac{5}{2} \iff -\frac{3}{2}<x-3<-\frac{1}{2} \Rightarrow -\frac{2}{3}>\frac{1}{x-3}>-2 \Rightarrow \left|\frac{1}{x-3}\right|<2$.

Luego, para todo $x\in X$ y $\delta<\frac{1}{2}$:
$$\left|\frac{x-4}{(x+1)(x-3)}-\frac{2}{3}\right| = \frac{|x-2||2x-3|}{3|x+1||x-3|} < \left(\frac{1}{3}\right)(\delta)(2)\left(\frac{2}{5}\right)(2) = \frac{8\delta}{15}$$

*(Ver gráfica en la página 62 del libro para apreciar la representación geométrica de este entorno).*

Luego, asumiendo $\frac{8\delta}{15}<\epsilon$ o, en forma equivalente, $\delta<\frac{15\epsilon}{8}$, tenemos:
$$(\forall\epsilon>0)\left(\exists\delta>0, \delta<\min\left\{\frac{1}{2},\frac{15\epsilon}{8}\right\}\right)(\forall x\in X): |x-2|<\delta \Rightarrow \left|\frac{x-4}{(x+1)(x-3)}-\frac{2}{3}\right|<\epsilon$$

Lo cual es equivalente a:
$$\lim_{x\rightarrow2}\frac{x-4}{(x+1)(x-3)}=\frac{2}{3}$$

### PROBLEMA 1.3.
Considerando $x_{0}\in\mathbb{R}$ probar las siguientes igualdades.

1. $\lim_{x\rightarrow x_{0}}k=k$
2. $\lim_{x\rightarrow x_{0}}(mx+b)=mx_{0}+b;\quad m\ne0$
3. $\lim_{x\rightarrow x_{0}}ax^{2}=ax_{0}^{2};\quad a\ne0$
4. $\lim_{x\rightarrow x_{0}}\sqrt{x}=\sqrt{x_{0}};\quad x_{0}\ge0$
5. $\lim_{x\rightarrow x_{0}}\sqrt[3]{x}=\sqrt[3]{x_{0}}$
6. $\lim_{x\rightarrow x_{0}}\frac{1}{x}=\frac{1}{x_{0}};\quad x_{0}\ne0$

**Solución.** Probamos los límites a partir de la definición (1.1.6, pág. 15).

#### 1) Probemos que $\lim_{x\rightarrow x_{0}}k=k$.
Es claro que el punto $x_{0}$ es un punto de acumulación del conjunto de definición $X=\mathbb{R}$ de la función $f(x)=k$.

Sea $\epsilon>0$; encontramos $\delta>0$ tal que para todo $x\in X$, $|x-x_{0}|<\delta \Rightarrow |f(x)-k|<\epsilon$.

Observemos que para todo $x\in X$:
$$|f(x)-k|=|k-k|=0<\epsilon$$

Luego, para todo $x\in X$ y todo $\delta>0$ se cumple que:
$$|x-x_{0}|<\delta \Rightarrow |f(x)-L|=0<\epsilon$$

Lo cual significa por definición que:
$$\lim_{x\rightarrow x_{0}}k=k$$

> **Observación 48.**
> El argumento que se ha esbozado para probar el resultado se fundamenta a partir de la lógica. Si la proposición $r$ es verdadera, entonces la proposición $q \Rightarrow r$ es verdadera para todo valor de verdad de la proposición $q$. En este caso la proposición $r: |f(x)-k|<\epsilon$ es verdadera, luego la proposición $q: |x-x_{0}|<\delta \Rightarrow r: |f(x)-L|<\epsilon$ es verdadera para cualquier valor de $\delta\in\mathbb{R}^{+}$.

#### 2) Probemos que $\lim_{x\rightarrow x_{0}}(mx+b)=mx_{0}+b$, con $m\ne0$.
Es claro que el punto $x_{0}$ es un punto de acumulación del conjunto de definición $X=\mathbb{R}$ de la función $f(x)=mx+b$.

Sea $\epsilon>0$. Encontremos $\delta>0$ tal que para todo $x\in X$, si $|x-x_{0}|<\delta$ entonces $|(mx+b)-(mx_{0}+b)|<\epsilon$.

Observemos que para todo $x\in X$ si $\delta\le\frac{\epsilon}{|m|}$ entonces:
$$|x-x_{0}|<\delta \Rightarrow |x-x_{0}|<\frac{\epsilon}{|m|} \Rightarrow |m||x-x_{0}|<\epsilon$$
$$\Rightarrow |m(x-x_{0})|<\epsilon \Rightarrow |mx-mx_{0}|<\epsilon$$
$$\Rightarrow |(mx+b)-(mx_{0}+b)|<\epsilon$$

Por lo tanto, se ha probado que para cada $\epsilon>0$, existe $\delta>0$, definido como $\delta\le\frac{\epsilon}{|m|}$, tal que para cada $x\in X$:
$$|x-x_{0}|<\delta \Rightarrow |(mx+b)-(mx_{0}+b)|<\epsilon$$

Lo cual significa por definición que:
$$\lim_{x\rightarrow x_{0}}(mx+b)=mx_{0}+b$$

#### 3) Probemos que $\lim_{x\rightarrow x_{0}}ax^{2}=ax_{0}^{2}$, con $a\ne0$.
Es claro que el punto $x_{0}$ es un punto de acumulación del conjunto de definición $X=\mathbb{R}$ de la función $f(x)=ax^{2}$.

Sea $\epsilon>0$. Encontremos $\delta>0$ tal que para todo $x\in X$, si $|x-x_{0}|<\delta$, entonces $|ax^{2}-ax_{0}^{2}|<\epsilon$.

Consideremos 3 situaciones con respecto a $x_{0}$:

i. **Supongamos $x_{0}<0$ y $0<\delta\le-\frac{x_{0}}{2}$**, entonces, para todo $x\in X$:
$$|x-x_{0}|<\delta \Rightarrow |x-x_{0}|<-\frac{x_{0}}{2} \Rightarrow \frac{x_{0}}{2}<x-x_{0}<-\frac{x_{0}}{2} \Rightarrow \frac{3x_{0}}{2}<x<\frac{x_{0}}{2}$$
$$\Rightarrow \frac{5x_{0}}{2}<x+x_{0}<\frac{3x_{0}}{2} \Rightarrow -\frac{3x_{0}}{2}<|x+x_{0}|<-\frac{5x_{0}}{2}$$

Luego, para todo $\epsilon>0$, existe $\delta>0$ definido como $\delta\le \min\left\{-\frac{x_{0}}{2}, -\frac{2\epsilon}{5|a|x_{0}}\right\}$ tal que para todo $x\in X$:
$$|x-x_{0}|<\delta \le \min\left\{-\frac{x_{0}}{2}, -\frac{2\epsilon}{5|a|x_{0}}\right\} \Rightarrow |a||x-x_{0}||x+x_{0}| < |a|\delta\left(-\frac{5x_{0}}{2}\right)$$
$$\Rightarrow |a||x^{2}-x_{0}^{2}| < |a|\left(-\frac{2\epsilon}{5|a|x_{0}}\right)\left(-\frac{5x_{0}}{2}\right) = \epsilon$$
$$\Rightarrow |ax^{2}-ax_{0}^{2}|<\epsilon$$

Lo cual significa por definición que:
$$\lim_{x\rightarrow x_{0}}ax^{2}=ax_{0}^{2};\quad a\ne0,\ x_{0}<0$$

ii. **Supongamos $x_{0}>0$ y $0<\delta\le\frac{x_{0}}{2}$**, entonces, para todo $x\in X$:
$$|x-x_{0}|<\delta \Rightarrow |x-x_{0}|<\frac{x_{0}}{2} \Rightarrow -\frac{x_{0}}{2}<x-x_{0}<\frac{x_{0}}{2} \Rightarrow \frac{x_{0}}{2}<x<\frac{3x_{0}}{2}$$
$$\Rightarrow \frac{3x_{0}}{2}<x+x_{0}<\frac{5x_{0}}{2} \Rightarrow \frac{3x_{0}}{2}<|x+x_{0}|<\frac{5x_{0}}{2}$$

Luego, para todo $\epsilon>0$, existe $\delta>0$, definido como $\delta<\min\left\{\frac{x_{0}}{2}, \frac{2\epsilon}{5|a|x_{0}}\right\}$ tal que para todo $x\in X$:
$$|x-x_{0}|<\delta < \min\left\{\frac{x_{0}}{2}, \frac{2\epsilon}{5|a|x_{0}}\right\} \Rightarrow |a||x-x_{0}||x+x_{0}| < |a|\delta\left(\frac{5x_{0}}{2}\right)$$
$$\Rightarrow |a||x^{2}-x_{0}^{2}| < |a|\left(\frac{2\epsilon}{5|a|x_{0}}\right)\left(\frac{5x_{0}}{2}\right) = \epsilon$$
$$\Rightarrow |ax^{2}-ax_{0}^{2}|<\epsilon$$

Lo cual significa por definición que:
$$\lim_{x\rightarrow x_{0}}ax^{2}=ax_{0}^{2};\quad a\ne0,\ x_{0}>0$$

iii. **Supongamos $x_{0}=0$ y $0<\delta\le\sqrt{\frac{\epsilon}{|a|}}$**, entonces, para todo $x\in X$:
$$|x-0|<\delta \Rightarrow |x|<\sqrt{\frac{\epsilon}{|a|}} \Rightarrow x^{2}<\left(\sqrt{\frac{\epsilon}{|a|}}\right)^{2}$$
$$\Rightarrow |ax^{2}| < |a|\left(\sqrt{\frac{\epsilon}{|a|}}\right)^{2} = \epsilon \Rightarrow |ax^{2}-0|<\epsilon$$

Lo cual significa por definición que:
$$\lim_{x\rightarrow0}ax^{2}=0;\quad a\ne0$$

Por lo tanto, de los 3 casos estudiados respecto a $x_{0}$, hemos probado que si $x_{0}\in\mathbb{R}$ entonces:
$$\lim_{x\rightarrow x_{0}}ax^{2}=ax_{0}^{2};\quad a\ne0$$

#### 4) Probemos que $\lim_{x\rightarrow x_{0}}\sqrt{x}=\sqrt{x_{0}}$, con $x_{0}\ge0$.

- **Sea $x_{0}>0$.**
Es claro que el punto $x_{0}$ es un punto de acumulación del conjunto de definición $X=[0,+\infty)$ de la función $f(x)=\sqrt{x}$.

Sea $\epsilon>0$ y $0<\delta<\frac{x_{0}}{4}$, entonces, para todo $x\in X$:
$$|x-x_{0}|<\delta \Rightarrow |x-x_{0}|<\frac{x_{0}}{4} \Rightarrow \frac{3x_{0}}{4}<x<\frac{5x_{0}}{4}$$
$$\Rightarrow \sqrt{\frac{3x_{0}}{4}}<\sqrt{x}<\sqrt{\frac{5x_{0}}{4}}$$
$$\Rightarrow \frac{\sqrt{3x_{0}}}{2}+\sqrt{x_{0}} < \sqrt{x}+\sqrt{x_{0}} < \frac{\sqrt{5x_{0}}}{2}+\sqrt{x_{0}}$$
$$\Rightarrow \frac{1}{\frac{\sqrt{3x_{0}}}{2}+\sqrt{x_{0}}} > \frac{1}{\sqrt{x}+\sqrt{x_{0}}} > \frac{1}{\frac{\sqrt{5x_{0}}}{2}+\sqrt{x_{0}}}$$
$$\Rightarrow \frac{1}{|\sqrt{x}+\sqrt{x_{0}}|} < \frac{1}{\sqrt{x_{0}}\left(1+\frac{\sqrt{3}}{2}\right)} = \frac{2}{\sqrt{x_{0}}(2+\sqrt{3})}$$

Luego, para todo $\epsilon>0$, existe $\delta>0$, con $\delta<\min\left\{\frac{x_{0}}{4}, \frac{\sqrt{x_{0}}(2+\sqrt{3})\epsilon}{2}\right\}$, tal que para todo $x\in X$:
$$|x-x_{0}|<\delta \Rightarrow |x-x_{0}|<\min\left\{\frac{x_{0}}{4}, \frac{\sqrt{x_{0}}(2+\sqrt{3})\epsilon}{2}\right\}$$
$$\Rightarrow \frac{|x-x_{0}|}{|\sqrt{x}+\sqrt{x_{0}}|} < \delta\left(\frac{2}{\sqrt{x_{0}}(2+\sqrt{3})}\right)$$
$$\Rightarrow \frac{|x-x_{0}|}{|\sqrt{x}+\sqrt{x_{0}}|} < \left(\frac{\sqrt{x_{0}}(2+\sqrt{3})\epsilon}{2}\right)\left(\frac{2}{\sqrt{x_{0}}(2+\sqrt{3})}\right) = \epsilon$$
$$\Rightarrow |\sqrt{x}-\sqrt{x_{0}}|<\epsilon$$

Lo cual significa por definición que:
$$\lim_{x\rightarrow x_{0}}\sqrt{x}=\sqrt{x_{0}};\quad x_{0}>0$$

- **Si $x_{0}=0$**, entonces, para todo $x\in X\cap B_{\delta}(0)$, tenemos:
$$x-0<\epsilon^{2} \Rightarrow x<\epsilon^{2} \Rightarrow \sqrt{x}<\epsilon \Rightarrow \sqrt{x}-0<\epsilon$$

Es decir, dado $\epsilon>0$ existe $\delta=\epsilon^{2}$ tal que si $x\in X\cap B_{\delta}(0)$, entonces $\sqrt{x}\in B_{\epsilon}(0)$; lo cual equivale a tener:
$$\lim_{x\rightarrow0}\sqrt{x}=0$$

De lo anterior, concluimos que:
$$\lim_{x\rightarrow x_{0}}\sqrt{x}=\sqrt{x_{0}};\quad x_{0}\ge0$$

#### 5) Probemos que $\lim_{x\rightarrow x_{0}}\sqrt[3]{x}=\sqrt[3]{x_{0}}$.
Es claro que el punto $x_{0}$ es un punto de acumulación del conjunto de definición $X=\mathbb{R}$ de la función $f(x)=\sqrt[3]{x}$.

Sea $\epsilon>0$. Encontremos $\delta>0$ tal que para todo $x\in X$ si $|x-x_{0}|<\delta$, entonces $|\sqrt[3]{x}-\sqrt[3]{x_{0}}|<\epsilon$.

Sin pérdida de generalidad supongamos que $\delta<\frac{|x_{0}|}{8}$, con $x_{0}\ne0$. Entonces:
$$|x-x_{0}|<\delta \Rightarrow |x-x_{0}|<\frac{|x_{0}|}{8} \Rightarrow x_{0}-\frac{|x_{0}|}{8}<x<x_{0}+\frac{|x_{0}|}{8}$$
$$|x-x_{0}|<\delta \Rightarrow \begin{cases} x_{0}-\frac{x_{0}}{8}<x<x_{0}+\frac{x_{0}}{8}, & \text{si } x_{0}>0 \\ x_{0}+\frac{x_{0}}{8}<x<x_{0}-\frac{x_{0}}{8}, & \text{si } x_{0}<0 \end{cases}$$
$$|x-x_{0}|<\delta \Rightarrow \begin{cases} 0<\frac{7x_{0}}{8}<x<\frac{9x_{0}}{8}, & \text{si } x_{0}>0 \\ \frac{9x_{0}}{8}<x<\frac{7x_{0}}{8}<0, & \text{si } x_{0}<0 \end{cases}$$

De acuerdo con la definición de límite, debemos acotar la expresión:
$$|\sqrt[3]{x}-\sqrt[3]{x_{0}}| = \frac{|x-x_{0}|}{|\sqrt[3]{x}^{2}+\sqrt[3]{xx_{0}}+\sqrt[3]{x_{0}}^{2}|}$$

para lo cual consideramos 3 casos.

i. **Supongamos $x_{0}>0$.**
Si $|x-x_{0}|<\delta<\frac{x_{0}}{8}$, entonces:
$$\frac{7x_{0}}{8}<x<\frac{9x_{0}}{8} \Rightarrow \sqrt[3]{\frac{7x_{0}}{8}}<\sqrt[3]{x}<\sqrt[3]{\frac{9x_{0}}{8}} \Rightarrow \frac{\sqrt[3]{7x_{0}}^{2}}{4}<\sqrt[3]{x}^{2}<\frac{\sqrt[3]{9x_{0}}^{2}}{4}$$
$$\frac{7x_{0}}{8}<x<\frac{9x_{0}}{8} \Rightarrow \sqrt[3]{\frac{7x_{0}}{8}}<\sqrt[3]{x}<\sqrt[3]{\frac{9x_{0}}{8}} \Rightarrow \frac{\sqrt[3]{7x_{0}^{2}}}{4}<\sqrt[3]{xx_{0}}<\frac{\sqrt[3]{9x_{0}^{2}}}{4}$$

Luego, si $|x-x_{0}|<\delta<\frac{x_{0}}{8}$ entonces:
$$\frac{\sqrt[3]{7x_{0}}^{2}}{4}+\frac{\sqrt[3]{7x_{0}^{2}}}{4}+\sqrt[3]{x_{0}}^{2} < \sqrt[3]{x}^{2}+\sqrt[3]{xx_{0}}+\sqrt[3]{x_{0}}^{2} < \frac{\sqrt[3]{9x_{0}^{2}}}{4}+\frac{\sqrt[3]{9x_{0}^{2}}}{4}+\sqrt[3]{x_{0}^{2}}$$
$$\Rightarrow \frac{1}{|\sqrt[3]{x}^{2}+\sqrt[3]{xx_{0}}+\sqrt[3]{x_{0}}^{2}|} < \frac{1}{\frac{\sqrt[3]{7x_{0}}^{2}}{4}+\frac{\sqrt[3]{7x_{0}^{2}}}{4}+\sqrt[3]{x_{0}}^{2}}$$
$$\Rightarrow \frac{1}{|\sqrt[3]{x}^{2}+\sqrt[3]{xx_{0}}+\sqrt[3]{x_{0}}^{2}|} < \frac{1}{x_{0}^{2/3}\left(\frac{7^{2/3}}{4}+\frac{7^{1/3}}{2}+1\right)}$$

Luego para todo $\epsilon>0$, si $x_{0}>0$ y asumiendo $\delta<\frac{x_{0}}{8}$ entonces:
$$|x-x_{0}|<\delta<\frac{x_{0}}{8} \Rightarrow |\sqrt[3]{x}-\sqrt[3]{x_{0}}| < \frac{\delta}{x_{0}^{2/3}\left(\frac{7^{2/3}}{4}+\frac{7^{1/3}}{2}+1\right)}$$

Ahora, si asumimos:
$$\frac{\delta}{x_{0}^{2/3}\left(\frac{7^{2/3}}{4}+\frac{7^{1/3}}{2}+1\right)} < \epsilon$$
y en consecuencia:
$$\delta < x_{0}^{2/3}\left(\frac{7^{2/3}}{4}+\frac{7^{1/3}}{2}+1\right)\epsilon$$

tenemos que para todo $\epsilon>0$ y todo $x>0$ existe $\delta<\min\left\{\frac{x_{0}}{8}, x_{0}^{2/3}\left(\frac{7^{2/3}}{4}+\frac{7^{1/3}}{2}+1\right)\epsilon\right\}$ tal que:
$$|x-x_{0}|<\delta \Rightarrow |\sqrt[3]{x}-\sqrt[3]{x_{0}}|<\epsilon$$

Con lo cual queda probado que, si $x_{0}>0$ entonces:
$$\lim_{x\rightarrow x_{0}}\sqrt[3]{x}=\sqrt[3]{x_{0}}$$

ii. **Supongamos $x_{0}<0$.**
Si $|x-x_{0}|<\delta<-\frac{x_{0}}{8}$, entonces:
$$\frac{9x_{0}}{8}<x<\frac{7x_{0}}{8}<0 \Rightarrow \sqrt[3]{\frac{9x_{0}}{8}}<\sqrt[3]{x}<\sqrt[3]{\frac{7x_{0}}{8}} \Rightarrow 0<\frac{\sqrt[3]{7x_{0}}^{2}}{4}<\sqrt[3]{x}^{2}<\frac{\sqrt[3]{9x_{0}}^{2}}{4}$$
$$\frac{9x_{0}}{8}<x<\frac{7x_{0}}{8}<0 \Rightarrow \sqrt[3]{\frac{9x_{0}}{8}}<\sqrt[3]{x}<\sqrt[3]{\frac{7x_{0}}{8}} \Rightarrow 0<\frac{\sqrt[3]{7x_{0}^{2}}}{4}<\sqrt[3]{xx_{0}}<\frac{\sqrt[3]{9x_{0}^{2}}}{4}$$

Luego, si $|x-x_{0}|<\delta<-\frac{x_{0}}{8}$ entonces:
$$\frac{\sqrt[3]{7x_{0}}^{2}}{4}+\frac{\sqrt[3]{7x_{0}^{2}}}{4}+\sqrt[3]{x_{0}}^{2} < \sqrt[3]{x}^{2}+\sqrt[3]{xx_{0}}+\sqrt[3]{x_{0}}^{2} < \frac{\sqrt[3]{9x_{0}^{2}}}{4}+\frac{\sqrt[3]{9x_{0}^{2}}}{4}+\sqrt[3]{x_{0}^{2}}$$
$$\Rightarrow \frac{1}{|\sqrt[3]{x}^{2}+\sqrt[3]{xx_{0}}+\sqrt[3]{x_{0}}^{2}|} < \frac{1}{\frac{\sqrt[3]{7x_{0}}^{2}}{4}+\frac{\sqrt[3]{7x_{0}^{2}}}{4}+\sqrt[3]{x_{0}}^{2}}$$
$$\Rightarrow \frac{1}{|\sqrt[3]{x}^{2}+\sqrt[3]{xx_{0}}+\sqrt[3]{x_{0}}^{2}|} < \frac{1}{|x_{0}|^{2/3}\left(\frac{7^{2/3}}{4}+\frac{7^{1/3}}{2}+1\right)}$$

Luego para todo $\epsilon>0$ si $x_{0}<0$ y asumiendo $\delta<-\frac{x_{0}}{8}$ entonces:
$$|x-x_{0}|<\delta<-\frac{x_{0}}{8} \Rightarrow |\sqrt[3]{x}-\sqrt[3]{x_{0}}| < \frac{\delta}{|x_{0}|^{2/3}\left(\frac{7^{2/3}}{4}+\frac{7^{1/3}}{2}+1\right)}$$

Ahora, si asumimos:
$$\frac{\delta}{|x_{0}|^{2/3}\left(\frac{7^{2/3}}{4}+\frac{7^{1/3}}{2}+1\right)} < \epsilon$$
y en consecuencia:
$$\delta < |x_{0}|^{2/3}\left(\frac{7^{2/3}}{4}+\frac{7^{1/3}}{2}+1\right)\epsilon$$

tenemos que para todo $\epsilon>0$ y todo $x<0$ existe $\delta<\min\left\{-\frac{x_{0}}{8}, |x_{0}|^{2/3}\left(\frac{7^{2/3}}{4}+\frac{7^{1/3}}{2}+1\right)\epsilon\right\}$ tal que:
$$|x-x_{0}|<\delta \Rightarrow |\sqrt[3]{x}-\sqrt[3]{x_{0}}|<\epsilon$$

Con lo cual queda probado que, si $x_{0}<0$, entonces:
$$\lim_{x\rightarrow x_{0}}\sqrt[3]{x}=\sqrt[3]{x_{0}}$$

iii. **Si $x_{0}=0$**, entonces, para todo $\epsilon>0$, existe $\delta>0$ con $\delta<\epsilon^{3}$ tal que para todo $x\in X$ tenemos:
$$|x-0|<\delta<\epsilon^{3} \Rightarrow |x|<\epsilon^{3} \Rightarrow \sqrt[3]{|x|}<\sqrt[3]{\epsilon^{3}} \Rightarrow |\sqrt[3]{x}-0|<\epsilon$$

Con lo cual queda probado que, si $x_{0}=0$ entonces:
$$\lim_{x\rightarrow x_{0}}\sqrt[3]{x}=\sqrt[3]{x_{0}}$$

De los 3 casos estudiados, concluimos que para todo $x_{0}\in\mathbb{R}$:
$$\lim_{x\rightarrow x_{0}}\sqrt[3]{x}=\sqrt[3]{x_{0}}$$

#### 6) Probemos que si $x_{0}\ne0$, entonces para $X=\mathbb{R}-\{0\}$ y $f(x)=\frac{1}{x}$:
$$\lim_{x\rightarrow x_{0}}\frac{1}{x}=\frac{1}{x_{0}}$$

para lo cual debemos acotar el valor absoluto $|f(x)-L|$ sabiendo que $x\in X$ y $|x-x_{0}|<\delta$, donde $L=\frac{1}{x_{0}}$.
$$|f(x)-L| = \left|\frac{1}{x}-\frac{1}{x_{0}}\right| = \left|\frac{x_{0}-x}{x_{0}x}\right| = \frac{|x-x_{0}|}{|x_{0}||x|};\quad \forall x\in X$$

Acotemos el módulo $\frac{|x-x_{0}|}{|x_{0}||x|}$ sabiendo que $|x-x_{0}|<\delta$. Sin pérdida de generalidad podemos suponer que $\delta<\frac{|x_{0}|}{2}$, de donde:
$$|x-x_{0}|<\delta \Rightarrow |x-x_{0}|<\frac{|x_{0}|}{2} \Rightarrow x_{0}-\frac{|x_{0}|}{2}<x<x_{0}+\frac{|x_{0}|}{2}$$

- Si $x_{0}<0$, entonces:
$$|x-x_{0}|<\delta \Rightarrow x_{0}+\frac{x_{0}}{2}<x<x_{0}-\frac{x_{0}}{2} \Rightarrow \frac{3x_{0}}{2}<x<\frac{x_{0}}{2}$$
$$\Rightarrow \frac{2}{3x_{0}}>\frac{1}{x}>\frac{2}{x_{0}} \Rightarrow \frac{1}{|x|}<\frac{2}{|x_{0}|}$$

- Si $x_{0}>0$, entonces:
$$|x-x_{0}|<\delta \Rightarrow x_{0}-\frac{x_{0}}{2}<x<x_{0}+\frac{x_{0}}{2} \Rightarrow \frac{x_{0}}{2}<x<\frac{3x_{0}}{2}$$
$$\Rightarrow \frac{2}{x_{0}}>\frac{1}{x}>\frac{2}{3x_{0}} \Rightarrow \frac{1}{|x|}<\frac{2}{|x_{0}|}$$

Luego, si $x_{0}\ne0$, entonces:
$$|x-x_{0}|<\delta \Rightarrow \frac{1}{|x|}<\frac{2}{|x_{0}|}$$

Por lo tanto:
$$|f(x)-L| = \frac{|x-x_{0}|}{|x_{0}||x|} < \frac{2\delta}{|x_{0}|^{2}};\quad \forall x\in X$$

Si tomamos $\frac{2\delta}{|x_{0}|^{2}}<\epsilon$, entonces $\delta<\frac{|x_{0}|^{2}\epsilon}{2}$.

Por lo tanto, dado $\epsilon>0$, existe $\delta>0$ definido como $\delta<\min\left\{\frac{|x_{0}|}{2}, \frac{|x_{0}|^{2}\epsilon}{2}\right\}$ tal que, para todo $x\in X$, se cumple que:
$$|x-x_{0}|<\delta \Rightarrow \left|\frac{1}{x}-\frac{1}{x_{0}}\right|<\epsilon$$

lo cual equivale a tener:
$$\lim_{x\rightarrow x_{0}}\frac{1}{x}=\frac{1}{x_{0}}$$

$\blacksquare$

### PROBLEMA 1.4.
Dada la función
$$f(x)=\begin{cases} bx^{2}+ab, & \text{si } x>0 \\ 2\sqrt{x^{2}+b}-b, & \text{si } x\le0 \end{cases}$$

Encontrar los valores de las constantes $a$ y $b$ que aseguren la existencia de $\lim_{x\rightarrow0}f(x)$ y que $f(1)=1$.

**Solución.** La existencia del límite $\lim_{x\rightarrow0}f(x)$ se garantiza a partir de la existencia de los límites laterales $\lim_{x\rightarrow0^{+}}f(x)$ y $\lim_{x\rightarrow0^{-}}f(x)$, y la igualdad de ellos. Es decir:
$$\lim_{x\rightarrow0}f(x)=L \iff L = \lim_{x\rightarrow0^{+}}f(x) = \lim_{x\rightarrow0^{-}}f(x)$$

$$L = \lim_{x\rightarrow0^{+}}(bx^{2}+ab) = \lim_{x\rightarrow0^{-}}(2\sqrt{x^{2}+b}-b)$$
$$L = ab = 2\sqrt{b}-b \tag{1.3}$$

Es decir que la existencia del límite $\lim_{x\rightarrow0}f(x)$ se garantiza siempre y cuando:
$$ab = 2\sqrt{b}-b$$

De otra parte, $f(1)=1$, es decir que:
$$b(1)^{2}+ab = 1 \Rightarrow b+ab = 1 \tag{1.4}$$

Resolviendo simultáneamente las ecuaciones (1.3) y (1.4) tenemos:
$$\begin{cases} ab = 2\sqrt{b}-b \\ b+ab = 1 \end{cases} \iff \begin{cases} ab = 2\sqrt{b}-b \\ ab = 1-b \end{cases}$$

Igualando las expresiones para $ab$:
$$2\sqrt{b}-b = 1-b \Rightarrow 2\sqrt{b} = 1 \Rightarrow \sqrt{b} = \frac{1}{2} \Rightarrow b = \frac{1}{4}$$

Sustituyendo $b = \frac{1}{4}$ en la segunda ecuación:
$$\frac{1}{4}a = 1 - \frac{1}{4} \Rightarrow \frac{1}{4}a = \frac{3}{4} \Rightarrow a = 3$$

*(Ver gráfica en la página 69 del libro para apreciar la continuidad y comportamiento de $f(x)$).*

Luego, $f$ definida como:
$$f(x)=\begin{cases} \frac{1}{4}(x^{2}+3), & \text{si } x>0 \\ \sqrt{4x^{2}+1}-\frac{1}{4}, & \text{si } x\le0 \end{cases}$$
es tal que $\lim_{x\rightarrow0}f(x)=\frac{3}{4}$ y $f(1)=1$.

**Solución.**

#### 1) Calculamos el límite: $\lim_{x\rightarrow0}\frac{\sqrt{1+x}-x-1}{x}$, el cual es de la forma $\left(\frac{0}{0}\right)$.

$$L = \lim_{x\rightarrow0}\frac{\sqrt{1+x}-x-1}{x} = \lim_{x\rightarrow0}\frac{\sqrt{1+x}-(x+1)}{x}$$
$$= \lim_{x\rightarrow0}\frac{[\sqrt{1+x}-(x+1)][\sqrt{1+x}+(x+1)]}{x[\sqrt{1+x}+(x+1)]}$$
$$= \lim_{x\rightarrow0}\frac{(1+x)-(x+1)^{2}}{x[\sqrt{1+x}+(x+1)]} = \lim_{x\rightarrow0}\frac{1+x-(x^{2}+2x+1)}{x[\sqrt{1+x}+(x+1)]}$$
$$= \lim_{x\rightarrow0}\frac{-x-x^{2}}{x[\sqrt{1+x}+(x+1)]} = \lim_{x\rightarrow0}\frac{-x(1+x)}{x[\sqrt{1+x}+(x+1)]}$$
$$= -\lim_{x\rightarrow0}\frac{1+x}{\sqrt{1+x}+(x+1)} = -\frac{1}{1+1} = -\frac{1}{2}$$

#### 2) El límite: $\lim_{x\rightarrow0}\frac{(1+x)^{5}-(1+5x)}{x^{2}+x^{5}}$ es de la forma $\left(\frac{0}{0}\right)$.

Presentamos 2 soluciones:

**(i) Simplificando las expresiones del numerador y del denominador.**
$$\lim_{x\rightarrow0}\frac{(1+x)^{5}-(1+5x)}{x^{2}+x^{5}} = \lim_{x\rightarrow0}\frac{1+5x+10x^{2}+10x^{3}+5x^{4}+x^{5}-1-5x}{x^{2}(1+x^{3})}$$
$$= \lim_{x\rightarrow0}\frac{x^{2}(10+10x+5x^{2}+x^{3})}{x^{2}(1+x^{3})}$$
$$= \lim_{x\rightarrow0}\frac{10+10x+5x^{2}+x^{3}}{1+x^{3}} = \frac{10}{1} = 10$$

**(ii) Haciendo un cambio de variable.**
Sea $t=1+x$, entonces cuando $x\rightarrow0$, $t\rightarrow1$:
$$\lim_{x\rightarrow0}\frac{(1+x)^{5}-(1+5x)}{x^{2}+x^{5}} = \lim_{t\rightarrow1}\frac{t^{5}-[1+5(t-1)]}{(t-1)^{2}+(t-1)^{5}}$$
$$= \lim_{t\rightarrow1}\frac{(t^{5}-1)-5(t-1)}{(t-1)^{2}[1+(t-1)^{3}]}$$
$$= \lim_{t\rightarrow1}\frac{(t-1)(t^{4}+t^{3}+t^{2}+t+1)-5(t-1)}{(t-1)^{2}[1+(t-1)^{3}]}$$
$$= \lim_{t\rightarrow1}\frac{(t-1)(t^{4}+t^{3}+t^{2}+t-4)}{(t-1)^{2}[1+(t-1)^{3}]}$$
$$= \lim_{t\rightarrow1}\frac{(t-1)^{2}(t^{3}+2t^{2}+3t+4)}{(t-1)^{2}[1+(t-1)^{3}]}$$
$$= \lim_{t\rightarrow1}\frac{t^{3}+2t^{2}+3t+4}{1+(t-1)^{3}} = \frac{1+2+3+4}{1+0} = 10$$

#### 3) El límite: $\lim_{x\rightarrow1}\frac{x^{100}-2x+1}{x^{50}-2x+1}$ es de la forma $\left(\frac{0}{0}\right)$.

Factorizando tanto el numerador como el denominador, tenemos:
$$L = \lim_{x\rightarrow1}\frac{x^{100}-2x+1}{x^{50}-2x+1}$$
$$= \lim_{x\rightarrow1}\frac{(x-1)(x^{99}+x^{98}+\cdots+x^{2}+x-1)}{(x-1)(x^{49}+x^{48}+\cdots+x^{2}+x-1)}$$
$$= \lim_{x\rightarrow1}\frac{x^{99}+x^{98}+\cdots+x^{2}+x-1}{x^{49}+x^{48}+\cdots+x^{2}+x-1}$$
$$= \frac{1^{99}+1^{98}+\cdots+1^{2}+1-1}{1^{49}+1^{48}+\cdots+1^{2}+1-1} = \frac{99-1}{49-1} = \frac{98}{48} = \frac{49}{24}$$

#### 4) Calculamos el límite: $\lim_{x\rightarrow7}\frac{\sqrt{x+2}-\sqrt[3]{x+20}}{\sqrt[4]{x+9}-2}$, el cual es indeterminado de la forma $\left(\frac{0}{0}\right)$.

Podemos proceder mediante un cambio de variable; sea $t=\sqrt[3]{x+20} \Rightarrow t^{3}=x+20 \Rightarrow x=t^{3}-20$.
Cuando $x\rightarrow7$, $t\rightarrow3$.

$$L = \lim_{x\rightarrow7}\frac{\sqrt{x+2}-\sqrt[3]{x+20}}{\sqrt[4]{x+9}-2} = \lim_{t\rightarrow3}\frac{\sqrt{(t^{3}-20)+2}-t}{\sqrt[4]{(t^{3}-20)+9}-2} = \lim_{t\rightarrow3}\frac{\sqrt{t^{3}-18}-t}{\sqrt[4]{t^{3}-11}-2}$$

Racionalizando tanto el numerador como el denominador tenemos:
$$L = \lim_{t\rightarrow3}\frac{(\sqrt{t^{3}-18}-t)(\sqrt{t^{3}-18}+t)\left(\sqrt[4]{t^{3}-11}^{3}+2\sqrt[4]{t^{3}-11}^{2}+2^{2}\sqrt[4]{t^{3}-11}+2^{3}\right)}{(\sqrt[4]{t^{3}-11}-2)\left(\sqrt[4]{t^{3}-11}^{3}+2\sqrt[4]{t^{3}-11}^{2}+2^{2}\sqrt[4]{t^{3}-11}+2^{3}\right)(\sqrt{t^{3}-18}+t)}$$
$$= \lim_{t\rightarrow3}\frac{(t^{3}-18-t^{2})\left(\sqrt[4]{t^{3}-11}^{3}+2\sqrt[4]{t^{3}-11}^{2}+4\sqrt[4]{t^{3}-11}+8\right)}{(t^{3}-11-16)(\sqrt{t^{3}-18}+t)}$$
$$= \lim_{t\rightarrow3}\frac{(t-3)(t^{2}+2t+6)\left(\sqrt[4]{t^{3}-11}^{3}+2\sqrt[4]{t^{3}-11}^{2}+4\sqrt[4]{t^{3}-11}+8\right)}{(t-3)(t^{2}+3t+9)(\sqrt{t^{3}-18}+t)}$$
$$= \lim_{t\rightarrow3}\frac{(t^{2}+2t+6)\left(\sqrt[4]{t^{3}-11}^{3}+2\sqrt[4]{t^{3}-11}^{2}+4\sqrt[4]{t^{3}-11}+8\right)}{(t^{2}+3t+9)(\sqrt{t^{3}-18}+t)}$$
$$= \frac{(9+6+6)(2^{3}+2(2^{2})+4(2)+8)}{(9+9+9)(3+3)} = \frac{(21)(8+8+8+8)}{(27)(6)} = \frac{21 \cdot 32}{162} = \frac{672}{162} = \frac{112}{27}$$

#### 5) El límite: $\lim_{x\rightarrow1}\frac{\sqrt{x}+\sqrt[3]{x}-2}{\sqrt[4]{x}-1}$ es indeterminado de la forma $\left(\frac{0}{0}\right)$.

Haciendo $x=t^{12}$, con $t\rightarrow1$:
$$L = \lim_{x\rightarrow1}\frac{\sqrt{x}+\sqrt[3]{x}-2}{\sqrt[4]{x}-1} = \lim_{t\rightarrow1}\frac{t^{6}+t^{4}-2}{t^{3}-1}$$

Factorizando el numerador y el denominador tenemos:
$$L = \lim_{t\rightarrow1}\frac{(t-1)(t^{5}+t^{4}+2t^{3}+2t^{2}+2t+2)}{(t-1)(t^{2}+t+1)}$$
$$= \lim_{t\rightarrow1}\frac{t^{5}+t^{4}+2t^{3}+2t^{2}+2t+2}{t^{2}+t+1} = \frac{1+1+2+2+2+2}{1+1+1} = \frac{10}{3}$$

#### 6) Calculamos el límite: $\lim_{x\rightarrow a^{+}}\frac{\sqrt{x}-\sqrt{a}+\sqrt{x-a}}{\sqrt{x^{2}-a^{2}}};\quad a>0$, el cual es indeterminado de la forma $\left(\frac{0}{0}\right)$.

$$L = \lim_{x\rightarrow a^{+}}\frac{\sqrt{x}-\sqrt{a}+\sqrt{x-a}}{\sqrt{x^{2}-a^{2}}}$$
$$= \lim_{x\rightarrow a^{+}}\frac{\sqrt{x}-\sqrt{a}}{\sqrt{x^{2}-a^{2}}} + \lim_{x\rightarrow a^{+}}\frac{\sqrt{x-a}}{\sqrt{x^{2}-a^{2}}}$$
$$= \lim_{x\rightarrow a^{+}}\frac{(\sqrt{x}-\sqrt{a})(\sqrt{x}+\sqrt{a})}{\sqrt{x-a}\sqrt{x+a}(\sqrt{x}+\sqrt{a})} + \lim_{x\rightarrow a^{+}}\frac{\sqrt{x-a}}{\sqrt{x-a}\sqrt{x+a}}$$
$$= \lim_{x\rightarrow a^{+}}\frac{x-a}{\sqrt{x-a}\sqrt{x+a}(\sqrt{x}+\sqrt{a})} + \lim_{x\rightarrow a^{+}}\frac{1}{\sqrt{x+a}}$$
$$= \lim_{x\rightarrow a^{+}}\frac{\sqrt{x-a}}{\sqrt{x+a}(\sqrt{x}+\sqrt{a})} + \lim_{x\rightarrow a^{+}}\frac{1}{\sqrt{x+a}} = \frac{0}{\sqrt{2a}(2\sqrt{a})} + \frac{1}{\sqrt{2a}} = \frac{1}{\sqrt{2a}};\quad a>0$$

#### 7) Calculamos el límite: $\lim_{x\rightarrow0^{+}}(\csc x - \cot x)$, el cual es indeterminado de la forma $(\infty-\infty)$.

$$L = \lim_{x\rightarrow0^{+}}(\csc x - \cot x) = \lim_{x\rightarrow0^{+}}\left(\frac{1}{\sin x}-\frac{\cos x}{\sin x}\right)$$
$$= \lim_{x\rightarrow0^{+}}\frac{1-\cos x}{\sin x} = \lim_{x\rightarrow0^{+}}\frac{(1-\cos x)(1+\cos x)}{\sin x(1+\cos x)}$$
$$= \lim_{x\rightarrow0^{+}}\frac{\sin^{2}x}{\sin x(1+\cos x)} = \lim_{x\rightarrow0^{+}}\frac{\sin x}{1+\cos x} = \frac{0}{1+1} = 0$$

#### 8) Calculamos el límite: $\lim_{x\rightarrow0}\operatorname{Ent}(x)\operatorname{Ent}(x+1)$, para lo cual usamos la definición de las funciones en una vecindad de $x_{0}=0$.

Sean $f(x)=\operatorname{Ent}(x)$ y $g(x)=\operatorname{Ent}(x+1)$:
$$\operatorname{Ent}(x) = \begin{cases} 0, & \text{si } 0\le x<1 \\ -1, & \text{si } -1\le x<0 \end{cases}$$
$$\operatorname{Ent}(x+1) = \begin{cases} 1, & \text{si } 1\le x+1<2 \\ 0, & \text{si } 0\le x+1<1 \end{cases} = \begin{cases} 1, & \text{si } 0\le x<1 \\ 0, & \text{si } -1\le x<0 \end{cases}$$

Límites laterales:
$$L^{-} = \lim_{x\rightarrow0^{-}}\operatorname{Ent}(x)\operatorname{Ent}(x+1) = \lim_{x\rightarrow0^{-}}(-1)(0) = 0$$
$$L^{+} = \lim_{x\rightarrow0^{+}}\operatorname{Ent}(x)\operatorname{Ent}(x+1) = \lim_{x\rightarrow0^{+}}(0)(1) = 0$$

Luego, dado que los límites laterales $L^{-}$ y $L^{+}$ existen y son iguales a 0, entonces:
$$\lim_{x\rightarrow0}\operatorname{Ent}(x)\operatorname{Ent}(x+1) = 0$$

#### 9) Calculamos el límite: $\lim_{x\rightarrow0}x\operatorname{Ent}\left(\frac{1}{x}\right)$

para lo cual calculamos los límites laterales usando el teorema de estricción. Teniendo en cuenta que la parte entera cumple la propiedad $t-1\le \operatorname{Ent}(t)\le t$, tenemos $\frac{1}{x}-1\le \operatorname{Ent}\left(\frac{1}{x}\right)\le\frac{1}{x}$.

- **Si $x<0$**, entonces:
$$\frac{1}{x}-1\le \operatorname{Ent}\left(\frac{1}{x}\right)\le\frac{1}{x} \Rightarrow x\left(\frac{1}{x}-1\right) \ge x\operatorname{Ent}\left(\frac{1}{x}\right) \ge x\left(\frac{1}{x}\right)$$
$$\Rightarrow 1-x \ge x\operatorname{Ent}\left(\frac{1}{x}\right) \ge 1$$

Ahora, $\lim_{x\rightarrow0^{-}}(1-x)=1$ y $\lim_{x\rightarrow0^{-}}1=1$, por lo tanto, por el teorema de estricción:
$$L^{-} = \lim_{x\rightarrow0^{-}}x\operatorname{Ent}\left(\frac{1}{x}\right) = 1$$

- **Si $x>0$**, entonces:
$$\frac{1}{x}-1\le \operatorname{Ent}\left(\frac{1}{x}\right)\le\frac{1}{x} \Rightarrow x\left(\frac{1}{x}-1\right) \le x\operatorname{Ent}\left(\frac{1}{x}\right) \le x\left(\frac{1}{x}\right)$$
$$\Rightarrow 1-x \le x\operatorname{Ent}\left(\frac{1}{x}\right) \le 1$$

Ahora, $\lim_{x\rightarrow0^{+}}(1-x)=1$ y $\lim_{x\rightarrow0^{+}}1=1$, por lo tanto, por el teorema de estricción:
$$L^{+} = \lim_{x\rightarrow0^{+}}x\operatorname{Ent}\left(\frac{1}{x}\right) = 1$$

Luego, dado que $L^{-}=L^{+}=1$:
$$\lim_{x\rightarrow0}x\operatorname{Ent}\left(\frac{1}{x}\right) = 1$$

#### 10) Calculamos el límite: $\lim_{x\rightarrow0}x^{3}\operatorname{Ent}\left(\frac{1}{x}\right)$

para lo cual calculamos los límites laterales usando el teorema de estricción. Sabemos que $\frac{1}{x}-1\le \operatorname{Ent}\left(\frac{1}{x}\right)\le\frac{1}{x}$.

- **Si $x<0$**, entonces $x^{3}<0$:
$$\frac{1}{x}-1\le \operatorname{Ent}\left(\frac{1}{x}\right)\le\frac{1}{x} \Rightarrow x^{3}\left(\frac{1}{x}-1\right) \ge x^{3}\operatorname{Ent}\left(\frac{1}{x}\right) \ge x^{3}\left(\frac{1}{x}\right)$$
$$\Rightarrow x^{2}-x^{3} \ge x^{3}\operatorname{Ent}\left(\frac{1}{x}\right) \ge x^{2}$$

Ahora, $\lim_{x\rightarrow0^{-}}(x^{2}-x^{3})=0$ y $\lim_{x\rightarrow0^{-}}x^{2}=0$, por lo tanto, por el teorema de estricción:
$$L^{-} = \lim_{x\rightarrow0^{-}}x^{3}\operatorname{Ent}\left(\frac{1}{x}\right) = 0$$

- **Si $x>0$**, entonces $x^{3}>0$:
$$\frac{1}{x}-1\le \operatorname{Ent}\left(\frac{1}{x}\right)\le\frac{1}{x} \Rightarrow x^{3}\left(\frac{1}{x}-1\right) \le x^{3}\operatorname{Ent}\left(\frac{1}{x}\right) \le x^{3}\left(\frac{1}{x}\right)$$
$$\Rightarrow x^{2}-x^{3} \le x^{3}\operatorname{Ent}\left(\frac{1}{x}\right) \le x^{2}$$

Ahora, $\lim_{x\rightarrow0^{+}}(x^{2}-x^{3})=0$ y $\lim_{x\rightarrow0^{+}}x^{2}=0$, por lo tanto, por el teorema de estricción:
$$L^{+} = \lim_{x\rightarrow0^{+}}x^{3}\operatorname{Ent}\left(\frac{1}{x}\right) = 0$$

Luego, dado que $L^{-}=L^{+}=0$, entonces:
$$\lim_{x\rightarrow0}x^{3}\operatorname{Ent}\left(\frac{1}{x}\right) = 0$$

#### 11) Calculamos el límite: $\lim_{x\rightarrow0}\frac{\sin(a+x)\sin(a+2x)-\sin^{2}a}{x}$, el cual es de la forma indeterminada $\left(\frac{0}{0}\right)$.

Por identidades trigonométricas tenemos:
- $\sin(a+x)\sin(a+2x) = \frac{\cos(a+x-a-2x)-\cos(a+x+a+2x)}{2} = \frac{\cos(-x)-\cos(2a+3x)}{2} = \frac{\cos x-\cos(2a+3x)}{2}$
- $\sin^{2}a = \frac{1-\cos 2a}{2}$

Luego:
$$L = \lim_{x\rightarrow0}\frac{\sin(a+x)\sin(a+2x)-\sin^{2}a}{x}$$
$$= \frac{1}{2}\lim_{x\rightarrow0}\frac{\cos x - \cos(2a+3x) - (1-\cos 2a)}{x}$$
$$= \frac{1}{2}\lim_{x\rightarrow0}\frac{\cos x - (\cos 2a\cos 3x - \sin 2a\sin 3x) - 1 + \cos 2a}{x}$$
$$= \frac{1}{2}\lim_{x\rightarrow0}\frac{(\cos x-1) - \cos 2a(\cos 3x-1) + \sin 2a\sin 3x}{x}$$

Usando propiedades del límite y resultados conocidos tenemos:
$$L = \frac{1}{2}\left[\lim_{x\rightarrow0}\frac{\cos x-1}{x} - \cos 2a\left(\lim_{x\rightarrow0}\frac{\cos 3x-1}{x}\right) + \sin 2a\left(\lim_{x\rightarrow0}\frac{\sin 3x}{x}\right)\right]$$
$$= \frac{1}{2}\left[\lim_{x\rightarrow0}\frac{\cos x-1}{x} - 3\cos 2a\left(\lim_{x\rightarrow0}\frac{\cos 3x-1}{3x}\right) + 3\sin 2a\left(\lim_{x\rightarrow0}\frac{\sin 3x}{3x}\right)\right]$$
$$= \frac{1}{2}[0 - (3\cos 2a)(0) + (3\sin 2a)(1)] = \frac{3\sin 2a}{2}$$

#### 12) Calculamos el límite: $\lim_{x\rightarrow0}\frac{1+\sin x-\cos x}{1+\sin px-\cos px}$, el cual es de la forma indeterminada $\left(\frac{0}{0}\right)$ para todo $p\ne0$.

Dividiendo tanto el numerador como el denominador entre $x$ y usando límites conocidos, tenemos:
$$L = \lim_{x\rightarrow0}\frac{1+\sin x-\cos x}{1+\sin px-\cos px} = \lim_{x\rightarrow0}\frac{\frac{1+\sin x-\cos x}{x}}{\frac{1+\sin px-\cos px}{x}}$$
$$= \frac{\lim_{x\rightarrow0}\frac{1-\cos x}{x} + \lim_{x\rightarrow0}\frac{\sin x}{x}}{\lim_{x\rightarrow0}\frac{1-\cos px}{x} + \lim_{x\rightarrow0}\frac{\sin px}{x}}$$
$$= \frac{0 + 1}{p\lim_{x\rightarrow0}\frac{1-\cos px}{px} + p\lim_{x\rightarrow0}\frac{\sin px}{px}} = \frac{0+1}{0+p} = \frac{1}{p};\quad p\ne0$$

> **Observación 49.**
> Si $p=0$, el límite no está bien definido.

#### 13) Calculamos el límite: $\lim_{x\rightarrow0}\frac{\sqrt{1+2\sin 3x}-\sqrt{1-4\sin 5x}}{\sin 6x}$, el cual es de la forma indeterminada $\left(\frac{0}{0}\right)$.

Multiplicamos numerador y denominador por el conjugado de $\sqrt{1+2\sin 3x}-\sqrt{1-4\sin 5x}$:
$$L = \lim_{x\rightarrow0}\frac{\sqrt{1+2\sin 3x}-\sqrt{1-4\sin 5x}}{\sin 6x}$$
$$= \lim_{x\rightarrow0}\frac{(\sqrt{1+2\sin 3x}-\sqrt{1-4\sin 5x})(\sqrt{1+2\sin 3x}+\sqrt{1-4\sin 5x})}{\sin 6x(\sqrt{1+2\sin 3x}+\sqrt{1-4\sin 5x})}$$
$$= \lim_{x\rightarrow0}\frac{(1+2\sin 3x)-(1-4\sin 5x)}{\sin 6x(\sqrt{1+2\sin 3x}+\sqrt{1-4\sin 5x})} = \lim_{x\rightarrow0}\frac{2\sin 3x + 4\sin 5x}{\sin 6x(\sqrt{1+2\sin 3x}+\sqrt{1-4\sin 5x})}$$

Dividiendo entre $x$ y separando en 2 límites tenemos:
$$L = \left(\lim_{x\rightarrow0}\frac{\frac{2\sin 3x + 4\sin 5x}{x}}{\frac{\sin 6x}{x}}\right)\left(\lim_{x\rightarrow0}\frac{1}{\sqrt{1+2\sin 3x}+\sqrt{1-4\sin 5x}}\right)$$
$$= \left(\frac{\lim_{x\rightarrow0}\frac{2\sin 3x}{x} + \lim_{x\rightarrow0}\frac{4\sin 5x}{x}}{\lim_{x\rightarrow0}\frac{\sin 6x}{x}}\right)\left(\lim_{x\rightarrow0}\frac{1}{\sqrt{1+2\sin 3x}+\sqrt{1-4\sin 5x}}\right)$$
$$= \left[\frac{(2)(3) + (4)(5)}{6}\right]\left(\frac{1}{1+1}\right) = \left(\frac{6+20}{6}\right)\left(\frac{1}{2}\right) = \left(\frac{26}{6}\right)\left(\frac{1}{2}\right) = \frac{13}{6}$$

#### 14) Calculamos el límite: $\lim_{x\rightarrow0}\frac{\tan 2x - 3\arcsin 4x}{\sin 5x - 6\arctan 7x}$, el cual es de la forma indeterminada $\left(\frac{0}{0}\right)$.

Dividiendo numerador y denominador entre $x$ tenemos:
$$L = \lim_{x\rightarrow0}\frac{\tan 2x - 3\arcsin 4x}{\sin 5x - 6\arctan 7x} = \lim_{x\rightarrow0}\frac{\frac{\tan 2x - 3\arcsin 4x}{x}}{\frac{\sin 5x - 6\arctan 7x}{x}}$$

#### 16) Calculamos el límite: $\lim_{x\rightarrow\infty}(\sqrt{x^{2}+3x+4}-\sqrt{x^{2}-3x+2})$.

Una buena estrategia para calcular el límite es racionalizar la expresión, para lo cual multiplicamos por el conjugado de la misma:
$$L = \lim_{x\rightarrow\infty}(\sqrt{x^{2}+3x+4}-\sqrt{x^{2}-3x+2})$$
$$= \lim_{x\rightarrow\infty}\frac{(\sqrt{x^{2}+3x+4}-\sqrt{x^{2}-3x+2})(\sqrt{x^{2}+3x+4}+\sqrt{x^{2}-3x+2})}{\sqrt{x^{2}+3x+4}+\sqrt{x^{2}-3x+2}}$$
$$= \lim_{x\rightarrow\infty}\frac{(x^{2}+3x+4)-(x^{2}-3x+2)}{\sqrt{x^{2}+3x+4}+\sqrt{x^{2}-3x+2}} = \lim_{x\rightarrow\infty}\frac{6x+2}{\sqrt{x^{2}+3x+4}+\sqrt{x^{2}-3x+2}}$$

Factorizando $x^{2}$ en cada uno de los radicales, tenemos:
$$L = \lim_{x\rightarrow\infty}\frac{6x+2}{\sqrt{x^{2}\left(1+\frac{3}{x}+\frac{4}{x^{2}}\right)} + \sqrt{x^{2}\left(1-\frac{3}{x}+\frac{2}{x^{2}}\right)}}$$
$$= \lim_{x\rightarrow\infty}\frac{6x+2}{|x|\sqrt{1+\frac{3}{x}+\frac{4}{x^{2}}} + |x|\sqrt{1-\frac{3}{x}+\frac{2}{x^{2}}}}$$
$$= \lim_{x\rightarrow\infty}\frac{6x+2}{|x|\left(\sqrt{1+\frac{3}{x}+\frac{4}{x^{2}}} + \sqrt{1-\frac{3}{x}+\frac{2}{x^{2}}}\right)}$$

- Si $x>0$, entonces $|x|=x$:
$$L^{+} = \lim_{x\rightarrow+\infty}\frac{6x+2}{x\left(\sqrt{1+\frac{3}{x}+\frac{4}{x^{2}}} + \sqrt{1-\frac{3}{x}+\frac{2}{x^{2}}}\right)}$$
$$= \lim_{x\rightarrow+\infty}\frac{6+\frac{2}{x}}{\sqrt{1+\frac{3}{x}+\frac{4}{x^{2}}} + \sqrt{1-\frac{3}{x}+\frac{2}{x^{2}}}} = \frac{6+0}{\sqrt{1+0+0}+\sqrt{1-0+0}} = \frac{6}{2} = 3$$

- Si $x<0$, entonces $|x|=-x$:
$$L^{-} = \lim_{x\rightarrow-\infty}\frac{6x+2}{-x\left(\sqrt{1+\frac{3}{x}+\frac{4}{x^{2}}} + \sqrt{1-\frac{3}{x}+\frac{2}{x^{2}}}\right)}$$
$$= \lim_{x\rightarrow-\infty}\frac{-6-\frac{2}{x}}{\sqrt{1+\frac{3}{x}+\frac{4}{x^{2}}} + \sqrt{1-\frac{3}{x}+\frac{2}{x^{2}}}} = \frac{-6-0}{\sqrt{1+0+0}+\sqrt{1-0+0}} = \frac{-6}{2} = -3$$

Luego, dado que $L^{+}\ne L^{-}$, el límite $\lim_{x\rightarrow\infty}(\sqrt{x^{2}+3x+4}-\sqrt{x^{2}-3x+2})$ no existe.

$$= \alpha_{1}\lim_{x\rightarrow0}\frac{\frac{a_{1}^{2}x^{2}}{2}}{x^{2}} + \lim_{x\rightarrow0}\frac{1-[1+(\cos(a_{2}x)-1)]^{\alpha_{2}}}{x^{2}} + \lim_{x\rightarrow0}\frac{1-\prod_{i=3}^{n}[\cos(a_{i}x)]^{\alpha_{i}}}{x^{2}}$$
$$= \frac{\alpha_{1}a_{1}^{2}}{2} - \lim_{x\rightarrow0}\frac{\alpha_{2}(\cos(a_{2}x)-1)}{x^{2}} + \lim_{x\rightarrow0}\frac{1-\prod_{i=3}^{n}[\cos(a_{i}x)]^{\alpha_{i}}}{x^{2}}$$
$$L = \frac{\alpha_{1}a_{1}^{2}}{2} + \frac{\alpha_{2}a_{2}^{2}}{2} + \lim_{x\rightarrow0}\frac{1-\prod_{i=3}^{n}[\cos(a_{i}x)]^{\alpha_{i}}}{x^{2}}$$
$$= \frac{\alpha_{1}a_{1}^{2}}{2} + \frac{\alpha_{2}a_{2}^{2}}{2} + \cdots + \frac{\alpha_{n}a_{n}^{2}}{2} = \frac{1}{2}\sum_{i=1}^{n}\alpha_{i}a_{i}^{2}$$

$\blacksquare$
