#### Ejercicio 1
Dada la ecuación:
$$F(x,y) = x^2 y - x\sqrt{y} = 0$$

**Solución:**
Calculamos $\frac{dy}{dx}$ a partir del algoritmo presentado:
* Derivamos ambos lados de la ecuación dada con respecto a $x$:

$$\frac{d}{dx}\left(x^2 y - x\sqrt{y}\right) = \frac{d}{dx}(0)$$

$$\frac{d}{dx}\left(x^2 y\right) - \frac{d}{dx}\left(x\sqrt{y}\right) = 0$$

$$y\frac{d}{dx}\left(x^2\right) + x^2\frac{d}{dx}(y) - \sqrt{y}\frac{d}{dx}(x) - x\frac{d}{dx}\left(\sqrt{y}\right) = 0$$

$$y(2x) + x^2 y' - \sqrt{y} - x\left(\frac{y'}{2\sqrt{y}}\right) = 0$$

$$2xy + x^2 y' - \sqrt{y} - \frac{xy'}{2\sqrt{y}} = 0$$

* Despejamos $y'$:

$$\left(x^2 - \frac{x}{2\sqrt{y}}\right) y' = \sqrt{y} - 2xy$$

$$y' = \frac{\sqrt{y} - 2xy}{x^2 - \frac{x}{2\sqrt{y}}}$$

#### Ejercicio 2
Considerando $F(x,y) = x^2 + y^2 - 1 = 0$, es fácil ver que: $x \in [-1,1]$ y $y \in [-1,1]$.

**Solución:**
Calculamos $\frac{dy}{dx}$ a partir del algoritmo presentado:
* Derivamos ambos lados de la ecuación dada con respecto a $x$:

$$\frac{d}{dx}\left(x^2 + y^2 - 1\right) = \frac{d}{dx}(0) \iff \frac{d}{dx}\left(x^2\right) + \frac{d}{dx}\left(y^2\right) - \frac{d}{dx}(1) = 0 \iff 2x + 2y y' = 0$$

* Despejamos $y'$:

$$2x + 2yy' = 0 \iff 2yy' = -2x \iff y' = -\frac{x}{y}$$

donde $x \in [-1,1]$ y $y \in [-1,1] \setminus \{0\}$.

> **Observación 63.**
> En este ejercicio es posible despejar la variable $y$ como una función explícita de la variable $x$. Por lo tanto, podemos calcular $y'$ sin usar el procedimiento de derivación implícita.
> Despejando la variable $y$ de la ecuación $x^2 + y^2 - 1 = 0$ tenemos (por ejemplo):
> $$x^2 + y^2 - 1 = 0 \implies y^2 = 1 - x^2 \implies y = \sqrt{1 - x^2}, \quad -1 \le x \le 1, \, 0 \le y \le 1$$
> Derivando con respecto a $x$, tenemos:
> $$y' = \frac{d}{dx}\left(\sqrt{1 - x^2}\right) = \frac{-2x}{2\sqrt{1 - x^2}} = \frac{-x}{\sqrt{1 - x^2}}$$

> **Observación 64.**
> Los resultados obtenidos en los 2 casos son equivalentes. Es cuestión de retomar por ejemplo el primer resultado obtenido:
> $$y' = \frac{-x}{y}, \quad x \in [-1,1], \, y \in [-1,1] \setminus \{0\}$$
> Si consideramos ahora $y = \sqrt{1 - x^2}$, con $x \in [-1,1]$ y $y \in [-1,1] \setminus \{0\}$, entonces:
> $$y' = \frac{-x}{y} = \frac{-x}{\sqrt{1 - x^2}}$$

#### Ejercicio 3
Dada la ecuación:
$$F(x,y) = x^2 + 2xy - y^2 - 2x = 0$$

**Solución:**
Calculamos $\frac{dy}{dx}$ a partir del algoritmo presentado:
* Derivamos ambos lados de la ecuación dada con respecto a $x$:

$$\frac{d}{dx}\left(x^2 + 2xy - y^2 - 2x\right) = \frac{d}{dx}(0)$$

$$\frac{d}{dx}\left(x^2\right) + \frac{d}{dx}(2xy) - \frac{d}{dx}\left(y^2\right) - \frac{d}{dx}(2x) = 0$$

$$2x + 2(xy' + y) - 2yy' - 2 = 0$$

* Despejamos $y'$:

$$2x + 2xy' + 2y - 2yy' - 2 = 0$$

$$(x + y - 1) + (x - y)y' = 0$$

$$(x - y)y' = 1 - y - x$$

$$y' = \frac{1 - y - x}{x - y}$$

#### Ejercicio 4
Dada la ecuación:
$$F(x,y) = \sqrt{x} + \sqrt{y} - \sqrt{a} = 0$$

**Solución:**
Calculamos $\frac{dy}{dx}$ a partir del algoritmo presentado:
* Derivamos ambos lados de la ecuación dada con respecto a $x$:

$$\frac{d}{dx}\left(\sqrt{x} + \sqrt{y} - \sqrt{a}\right) = \frac{d}{dx}(0)$$

$$\frac{d}{dx}\left(\sqrt{x}\right) + \frac{d}{dx}\left(\sqrt{y}\right) - \frac{d}{dx}\left(\sqrt{a}\right) = 0$$

$$\frac{1}{2\sqrt{x}} + \frac{y'}{2\sqrt{y}} = 0$$

* Despejamos $y'$:

$$\frac{1}{2\sqrt{x}} + \frac{y'}{2\sqrt{y}} = 0 \iff \frac{y'}{\sqrt{y}} = -\frac{1}{\sqrt{x}} \iff y' = -\frac{\sqrt{y}}{\sqrt{x}} \iff y' = -\sqrt{\frac{y}{x}}$$

#### Ejercicio 5
Dada la ecuación:
$$F(x,y) = x^{2/3} + y^{2/3} - a^{2/3} = 0$$

**Solución:**
Calculamos $\frac{dy}{dx}$ a partir del algoritmo presentado:
* Derivamos ambos lados de la ecuación dada con respecto a $x$:

$$\frac{d}{dx}\left(x^{2/3} + y^{2/3} - a^{2/3}\right) = \frac{d}{dx}(0)$$

$$\frac{d}{dx}\left(x^{2/3}\right) + \frac{d}{dx}\left(y^{2/3}\right) - \frac{d}{dx}\left(a^{2/3}\right) = 0$$

$$\frac{2x^{-1/3}}{3} + \frac{2y' y^{-1/3}}{3} = 0$$

$$\frac{1}{x^{1/3}} + \frac{y'}{y^{1/3}} = 0$$

* Despejamos $y'$:

$$\frac{1}{x^{1/3}} + \frac{y'}{y^{1/3}} = 0 \iff \frac{y'}{y^{1/3}} = -\frac{1}{x^{1/3}} \iff y' = -\frac{y^{1/3}}{x^{1/3}} \iff y' = -\sqrt[3]{\frac{y}{x}}$$

#### Ejercicio 6
Dada la ecuación:
$$F(x,y) = \arctan\left(\frac{y}{x}\right) - \ln\sqrt{x^2 + y^2} = 0$$

**Solución:**
Calculamos $\frac{dy}{dx}$ a partir del algoritmo presentado:
* Derivamos ambos lados de la ecuación dada con respecto a $x$:

$$\frac{d}{dx}\left(\arctan\left(\frac{y}{x}\right) - \ln\sqrt{x^2 + y^2}\right) = \frac{d}{dx}(0)$$

$$\frac{d}{dx}\left(\arctan\left(\frac{y}{x}\right)\right) - \frac{d}{dx}\left(\ln\sqrt{x^2 + y^2}\right) = 0$$

$$\frac{1}{1 + \left(\frac{y}{x}\right)^2} \left[\frac{d}{dx}\left(\frac{y}{x}\right)\right] - \frac{1}{\sqrt{x^2 + y^2}} \left[\frac{d}{dx}\left(\sqrt{x^2 + y^2}\right)\right] = 0$$

$$\frac{1}{1 + \left(\frac{y}{x}\right)^2} \left[\frac{x y' - y}{x^2}\right] - \frac{1}{\sqrt{x^2 + y^2}} \left[\frac{2x + 2y y'}{2\sqrt{x^2 + y^2}}\right] = 0$$

$$\frac{x y' - y}{x^2 + y^2} - \frac{x + y y'}{x^2 + y^2} = 0$$

* Despejamos $y'$:

$$x y' - y - x - y y' = 0 \iff x y' - y y' = x + y \iff y'(x - y) = x + y \iff y' = \frac{x + y}{x - y}$$

### Regla de la Cadena y Derivadas de Funciones Compuestas

#### EJERCICIO 2.27
Sean $y = f(u) = u^3 - 2u^2 + 1$ y $u(x) = \sqrt{2x + 1}$. Calcular $\frac{dy}{dx}$.

**Solución:**
$$\frac{dy}{dx} = \left(\frac{dy}{du}\right)\left(\frac{du}{dx}\right) = \left(3u^2 - 4u\right)\left(\frac{2}{2\sqrt{2x + 1}}\right) = \frac{3u^2 - 4u}{\sqrt{2x + 1}}$$

#### EJERCICIO 2.28
Sean $y = f(u) = 3u 2^u$ y $u(x) = x \ln x$. Calcular $\frac{dy}{dx}$.

**Solución:**
$$\frac{dy}{dx} = \left(\frac{dy}{du}\right)\left(\frac{du}{dx}\right) = 3\left(2^u + u 2^u \ln 2\right)(1 + \ln x) = 3 \cdot 2^u (1 + u \ln 2)(1 + \ln x)$$

#### EJERCICIO 2.29
Sean $y = f(x) = x \sin x$ y $x(t) = t^2 - t + 1$. Calcular $\frac{dy}{dt}$.

**Solución:**
$$\frac{dy}{dt} = \left(\frac{dy}{dx}\right)\left(\frac{dx}{dt}\right) = (\sin x + x \cos x)(2t - 1)$$

#### EJERCICIO 2.30
Sean $x$ e $y$ dependientes de la variable $t$, tales que $x^2 - y^2 = 1$. Suponiendo conocido $\frac{dx}{dt}$, calcular $\frac{dy}{dt}$.

**Solución:**
Sabiendo que tanto $x$ como $y$ dependen de la variable $t$, podemos escribir la ecuación $x^2 - y^2 = 1$ de la siguiente forma:
$$x^2(t) - y^2(t) = 1$$

Derivando ambos lados con respecto a la variable $t$, teniendo en cuenta la regla de la cadena y las propiedades de la derivada, tenemos:

$$\frac{d}{dt}\left(x^2(t) - y^2(t)\right) = \frac{d}{dt}(0) \iff \frac{d}{dt}\left(x^2(t)\right) - \frac{d}{dt}\left(y^2(t)\right) = 0$$

$$2x(t)\frac{dx}{dt} - 2y(t)\frac{dy}{dt} = 0 \iff 2x(t)\frac{dx}{dt} = 2y(t)\frac{dy}{dt} \iff \frac{dy}{dt} = \frac{x(t)\left(\frac{dx}{dt}\right)}{y(t)}$$

### 2.5.1. Derivación Logarítmica

Sea $f$ una función de variable y valor reales definida para todo $x \in \mathbb{R}$ tal que $f(x) > 0$. La derivación logarítmica es una técnica que permite calcular la derivada de $f$ usando las propiedades básicas del logaritmo y la regla de la cadena. Esta estrategia se puede considerar como un algoritmo, el cual a partir de los pasos indicados permite calcular $\frac{df}{dx}$. Los pasos a seguir son los siguientes:

* **Paso 1.** Hacer $y = f(x)$.
* **Paso 2.** Aplicar la función logaritmo en ambos lados de la ecuación:
  $$\log_b y = \log_b f(x), \quad b > 0, \, b \neq 1$$
* **Paso 3.** Derivar ambos lados de la ecuación teniendo en cuenta: la derivada de la función logaritmo, la regla de la cadena y el hecho de que $y = f(x)$:
  $$\frac{d}{dx}(\log_b y) = \frac{d}{dx}(\log_b f(x))$$
* **Paso 4.** Despejar $y'$.

---

#### EJERCICIO 2.31
Calcular la derivada de $f$ usando la técnica de derivación logarítmica:

1. $f(x) = x \sqrt{\frac{1-x}{1+x}}$
2. $f(x) = (x - a_1)^{\alpha_1} (x - a_2)^{\alpha_2} \cdots (x - a_n)^{\alpha_n}$
3. $f(x) = \frac{x^2}{1-x} \sqrt[3]{\frac{3-x}{(3+x)^2}}$
4. $f(x) = \left(x + \sqrt{1 + x^2}\right)^n$
5. $f(x) = \sqrt{\phi^2(x) + \psi^2(x)}$; donde $\phi$ y $\psi$ son funciones derivables de $x$.

**Solución:**

1. Sea $y = x \sqrt{\frac{1-x}{1+x}}$. Aplicando logaritmo natural tenemos:
   $$\ln y = \ln\left(x \sqrt{\frac{1-x}{1+x}}\right) = \ln x + \ln \sqrt{\frac{1-x}{1+x}} = \ln x + \frac{1}{2}\ln\left(\frac{1-x}{1+x}\right) = \ln x + \frac{1}{2}[\ln(1-x) - \ln(1+x)]$$

   Derivando con respecto a $x$ ambos lados de la ecuación:
   $$\frac{d}{dx}(\ln y) = \frac{d}{dx}\left(\ln x + \frac{1}{2}[\ln(1-x) - \ln(1+x)]\right)$$
   $$\frac{y'}{y} = \frac{1}{x} + \frac{1}{2}\left[\frac{-1}{1-x} - \frac{1}{1+x}\right] = \frac{1}{x} - \frac{1}{1-x^2}$$

   Despejando $y'$:
   $$y' = y \left(\frac{1}{x} - \frac{1}{1-x^2}\right) = y \left[\frac{1 - x - x^2}{x(1-x^2)}\right]$$

   Luego:
   $$f'(x) = \sqrt{\frac{1-x}{1+x}} \left[\frac{1 - x - x^2}{1-x^2}\right] = \frac{1 - x - x^2}{(1+x)\sqrt{1-x^2}}, \quad |x| < 1$$

2. Sea $y = f(x) = (x - a_1)^{\alpha_1} (x - a_2)^{\alpha_2} \cdots (x - a_n)^{\alpha_n}$. Usando el símbolo de productoria:
   $$y = f(x) = \prod_{k=1}^n (x - a_k)^{\alpha_k}$$

   Aplicando logaritmo natural:
   $$\ln y = \ln \prod_{k=1}^n (x - a_k)^{\alpha_k} = \sum_{k=1}^n \ln (x - a_k)^{\alpha_k} = \sum_{k=1}^n \alpha_k \ln(x - a_k)$$

   Derivando con respecto a $x$ ambos lados:
   $$\frac{d}{dx}(\ln y) = \frac{d}{dx}\left(\sum_{k=1}^n \alpha_k \ln(x - a_k)\right)$$
   $$\frac{y'}{y} = \sum_{k=1}^n \alpha_k \left[\frac{d}{dx}(\ln(x - a_k))\right] = \sum_{k=1}^n \alpha_k \left(\frac{1}{x - a_k}\right)$$

   Despejando $y'$:
   $$y' = y \sum_{k=1}^n \frac{\alpha_k}{x - a_k}$$

   Luego:
   $$f'(x) = \left(\prod_{k=1}^n (x - a_k)^{\alpha_k}\right) \left(\sum_{k=1}^n \frac{\alpha_k}{x - a_k}\right), \quad x \neq a_k, \, k=1,2,\dots,n$$

3. Sea $y = f(x) = \frac{x^2}{1-x} \sqrt[3]{\frac{3-x}{(3+x)^2}}$. Aplicando logaritmo natural:
   $$\ln y = \ln\left[\frac{x^2}{1-x} \sqrt[3]{\frac{3-x}{(3+x)^2}}\right] = \ln\left(\frac{x^2}{1-x}\right) + \ln \sqrt[3]{\frac{3-x}{(3+x)^2}}$$
   $$= \ln x^2 - \ln(1-x) + \frac{1}{3} \ln \frac{3-x}{(3+x)^2} = 2\ln x - \ln(1-x) + \frac{1}{3}[\ln(3-x) - 2\ln(3+x)]$$

   Derivando con respecto a $x$ ambos lados:
   $$\frac{d}{dx}(\ln y) = \frac{d}{dx}\left(2\ln x - \ln(1-x) + \frac{1}{3}[\ln(3-x) - 2\ln(3+x)]\right)$$
   $$\frac{y'}{y} = \frac{2}{x} - \frac{-1}{1-x} + \frac{1}{3}\left(\frac{-1}{3-x} - \frac{2}{3+x}\right) = \frac{2x^3 + 4x^2 - 36x + 54}{3x(x-1)(x^2-9)}$$

   Despejando $y'$:
   $$y' = y \left[\frac{2x^3 + 4x^2 - 36x + 54}{3x(x-1)(x^2-9)}\right] = \frac{x^2}{1-x} \sqrt[3]{\frac{3-x}{(3+x)^2}} \left[\frac{2x^3 + 4x^2 - 36x + 54}{3x(x-1)(x^2-9)}\right]$$

   Luego:
   $$f'(x) = \frac{2}{3}\left(\frac{x^4 + 2x^3 - 18x^2 + 27x}{(x^2-1)(x^2-9)}\right)\sqrt[3]{\frac{x-3}{(3+x)^2}}, \quad x \in (-\infty,1) \cup (3,+\infty)$$

4. Sea $y = f(x) = \left(x + \sqrt{1+x^2}\right)^n$. Aplicando logaritmo natural:
   $$\ln y = \ln\left(x + \sqrt{1+x^2}\right)^n = n \ln\left(x + \sqrt{1+x^2}\right)$$

   Derivando con respecto a $x$ ambos lados:
   $$\frac{d}{dx}(\ln y) = \frac{d}{dx}\left(n \ln\left(x + \sqrt{1+x^2}\right)\right)$$
   $$\frac{y'}{y} = n \left[\frac{\frac{d}{dx}\left(x + \sqrt{1+x^2}\right)}{x + \sqrt{1+x^2}}\right] = \frac{n}{\sqrt{1+x^2}}$$

   Despejando $y'$:
   $$y' = y \left(\frac{n}{\sqrt{1+x^2}}\right) = \frac{n\left(x + \sqrt{1+x^2}\right)^n}{\sqrt{1+x^2}}$$

   Luego:
   $$f'(x) = \frac{n\left(x + \sqrt{1+x^2}\right)^n}{\sqrt{1+x^2}}, \quad x \in \mathbb{R}$$

5. Sea $y = f(x) = \sqrt{\phi^2(x) + \psi^2(x)}$. Aplicando logaritmo natural:
   $$\ln y = \ln \sqrt{\phi^2(x) + \psi^2(x)} = \frac{1}{2} \ln[\phi^2(x) + \psi^2(x)]$$

   Derivando con respecto a $x$ ambos lados:
   $$\frac{d}{dx}(\ln y) = \frac{d}{dx}\left(\frac{1}{2}\ln[\phi^2(x) + \psi^2(x)]\right)$$
   $$\frac{y'}{y} = \frac{1}{2} \left[\frac{\frac{d}{dx}(\phi^2(x) + \psi^2(x))}{\phi^2(x) + \psi^2(x)}\right] = \frac{1}{2} \left[\frac{2\phi(x)\phi'(x) + 2\psi(x)\psi'(x)}{\phi^2(x) + \psi^2(x)}\right] = \frac{\phi(x)\phi'(x) + \psi(x)\psi'(x)}{\phi^2(x) + \psi^2(x)}$$

   Despejando $y'$:
   $$y' = y \left[\frac{\phi(x)\phi'(x) + \psi(x)\psi'(x)}{\phi^2(x) + \psi^2(x)}\right] = \sqrt{\phi^2(x) + \psi^2(x)} \left[\frac{\phi(x)\phi'(x) + \psi(x)\psi'(x)}{\phi^2(x) + \psi^2(x)}\right]$$

   Luego:
   $$f'(x) = \frac{\phi(x)\phi'(x) + \psi(x)\psi'(x)}{\sqrt{\phi^2(x) + \psi^2(x)}}$$

## 2.6. Interpretación Geométrica de la Derivada en un Punto

> **DEFINICIÓN 2.6.1 (Recta tangente.)**
> Sea $f$ una función derivable en $a$. Se define la recta tangente a la curva de $f$ en el punto $P(a,f(a))$ como la recta que pasa por el punto $P$ y cuya pendiente es $m_T = f'(a)$.

> **Observación 65.**
> De acuerdo con la definición de recta tangente, la ecuación de la recta tangente a la curva de $f$ en el punto $P(a,f(a))$ es:
> $$T: y = f'(a)(x - a) + f(a)$$

> **DEFINICIÓN 2.6.2 (Recta normal.)**
> Sea $f$ una función derivable en $a$. Se define la recta normal a la curva de $f$ en el punto $P(a,f(a))$ como la recta que pasa por el punto $P$ y es perpendicular a la recta tangente a la curva de $f$ en el punto $P$.

> **Observación 66.**
> De acuerdo con la definición de recta normal, la ecuación de la recta normal a la curva de $f$ en el punto $P(a,f(a))$ es:
> 1. Si $f'(a) \neq 0$, entonces $N: y = \left[\frac{-1}{f'(a)}\right](x - a) + f(a)$.
> 2. Si $f'(a) = 0$, entonces $N: x = a$.

*(Nota: Para apreciar el comportamiento geométrico de las rectas tangente y normal en los casos $f'(a) \neq 0$ y $f'(a) = 0$, ver las **Figura 2.3** y **Figura 2.4** en la página 128 del libro).*

#### EJERCICIO 2.32
Encontrar la ecuación de la recta tangente y la ecuación de la recta normal a la curva de la función $f$ en el punto $a$ y hacer una gráfica donde se muestren la curva de $f$ y las rectas tangente y normal.

**Solución General:**
Para definir la ecuación de la recta tangente es necesario calcular la pendiente de la recta, la cual por definición es la derivada de la función $f$ en el punto $P(a,f(a))$. Por lo tanto, será necesario calcular la derivada de $f$. Para definir la ecuación de la recta normal es necesario calcular la pendiente de la recta, la cual por definición es el negativo del recíproco de la pendiente de la recta tangente, siempre que esta no sea cero.

1. $f(x) = x^3 - 4x^2 + 5x - 3; \quad a = 2$
   * **Derivada de $f$:** $f'(x) = \frac{d}{dx}(x^3 - 4x^2 + 5x - 3) = 3x^2 - 8x + 5$
   * **Pendiente de la recta tangente en $P(2,f(2))$:** $m_T(2) = f'(2) = 1$
   * **Ecuación de la recta tangente en $P(2,-1)$:**
     $$T: y - f(2) = m_T(2)(x - 2) \iff y - (-1) = (1)(x - 2) \iff y = x - 3$$
   * **Pendiente de la recta normal en $P(2,f(2))$:** $m_N(2) = \frac{-1}{f'(2)} = -1$
   * **Ecuación de la recta normal en $P(2,-1)$:**
     $$N: y - f(2) = m_N(2)(x - 2) \iff y - (-1) = (-1)(x - 2) \iff y = 1 - x$$
   *(Para apreciar la curva de $f$, la recta tangente y la recta normal en $P(2,-1)$, mirar la **Figura 2.5** en la página 129 del libro).*

2. $f(x) = \sqrt{5 - x^2}; \quad a = 1$
   * **Derivada de $f$:** $f'(x) = \frac{d}{dx}\left(\sqrt{5 - x^2}\right) = \frac{-x}{\sqrt{5 - x^2}}$
   * **Pendiente de la recta tangente en $P(1,f(1))$:** $m_T(1) = f'(1) = -\frac{1}{2}$
   * **Ecuación de la recta tangente en $P(1,2)$:**
     $$T: y - f(1) = m_T(1)(x - 1) \iff y - 2 = \left(-\frac{1}{2}\right)(x - 1) \iff y = \frac{5}{2} - \frac{x}{2}$$
   * **Pendiente de la recta normal en $P(1,f(1))$:** $m_N(1) = \frac{-1}{f'(1)} = 2$
   * **Ecuación de la recta normal en $P(1,2)$:**
     $$N: y - f(1) = m_N(1)(x - 1) \iff y - 2 = 2(x - 1) \iff y = 2x$$
   *(Para apreciar la curva de $f$, la recta tangente y la recta normal en $P(1,2)$, mirar la **Figura 2.6** en la página 129 del libro).*

3. $f(x) = \frac{x^3 + 2x^2}{(x - 1)^2}; \quad a = -2$
   * **Derivada de $f$:**
     $$f'(x) = \frac{d}{dx}\left(\frac{x^3 + 2x^2}{(x - 1)^2}\right) = \frac{(x - 1)^2(3x^2 + 4x) - 2(x - 1)(x^3 + 2x^2)}{(x - 1)^4} = \frac{x(x - 4)(x + 1)}{(x - 1)^3}$$
   * **Pendiente de la recta tangente en $P(-2,f(-2))$:** $m_T(-2) = f'(-2) = \frac{4}{9}$
   * **Ecuación de la recta tangente en $P(-2,0)$:**
     $$T: y - f(-2) = m_T(-2)(x - (-2)) \iff y - 0 = \left(\frac{4}{9}\right)(x + 2) \iff y = \frac{4}{9}(x + 2)$$
   * **Pendiente de la recta normal en $P(-2,f(-2))$:** $m_N(-2) = \frac{-1}{f'(-2)} = -\frac{9}{4}$
   * **Ecuación de la recta normal en $P(-2,0)$:**
     $$N: y - f(-2) = m_N(-2)(x - (-2)) \iff y - 0 = \left(-\frac{9}{4}\right)(x + 2) \iff y = -\frac{9}{4}x - \frac{9}{2}$$

## 2.7. Problemas que Involucran la Derivada

#### PROBLEMA 2.6
Probar los siguientes resultados conocidos de derivadas:

1. \frac{d}{dx}(c) = 0
2. \frac{d}{dx}(mx + b) = m, \quad m \neq 0
3. \frac{d}{dx}(ax^2 + bx + c) = 2ax + b, \quad a \neq 0
4. \frac{d}{dx}\left(\frac{1}{x}\right) = -\frac{1}{x^2}, \quad x \neq 0
5. \frac{d}{dx}(\sqrt{x}) = \frac{1}{2\sqrt{x}}, \quad x > 0
6. \frac{d}{dx}(\sqrt[3]{x}) = \frac{1}{3\sqrt[3]{x^2}}, \quad x \neq 0
7. \frac{d}{dx}(|x|) = \operatorname{sgn}(x), \quad x \neq 0
8. \frac{d}{dx}(\lfloor x \rfloor) = 0, \quad x \notin \mathbb{Z}
9. \frac{d}{dx}(\sin x) = \cos x
10. \frac{d}{dx}(\cos x) = -\sin x
11. \frac{d}{dx}(\sinh x) = \cosh x
12. \frac{d}{dx}(\cosh x) = \sinh x
13. \frac{d}{dx}(a^x) = a^x \ln a, \quad a > 0, \, a \neq 1
14. \frac{d}{dx}(\log_a x) = \frac{1}{x \ln a}, \quad x > 0
15. \frac{d}{dx}(x^\alpha) = \alpha x^{\alpha-1}, \quad x > 0, \, \alpha \in \mathbb{R}

**Solución:**
Para probar los resultados dados, usamos la definición de derivada por límite: $\lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$.

1. **Sea $f(x) = c$:**
   $$\lim_{h \to 0} \frac{f(x+h) - f(x)}{h} = \lim_{h \to 0} \frac{c - c}{h} = \lim_{h \to 0} \frac{0}{h} = 0$$
   Por lo tanto, $\frac{d}{dx}(c) = 0$ para todo $x \in \mathbb{R}$.

2. **Sea $f(x) = mx + b$ ($m \neq 0$):**
   $$\lim_{h \to 0} \frac{f(x+h) - f(x)}{h} = \lim_{h \to 0} \frac{[m(x+h) + b] - (mx + b)}{h} = \lim_{h \to 0} \frac{mh}{h} = m$$
   Por lo tanto, $\frac{d}{dx}(mx + b) = m$.
   > **Observación 67.** Casos particulares:
   > i. Si $m=1, b=0 \implies \frac{d}{dx}(x) = 1$ (derivada de la función identidad).
   > ii. Si $m=-1, b=0 \implies \frac{d}{dx}(-x) = -1$.

3. **Sea $f(x) = ax^2 + bx + c$ ($a \neq 0$):**
   $$\lim_{h \to 0} \frac{[a(x+h)^2 + b(x+h) + c] - (ax^2 + bx + c)}{h} = \lim_{h \to 0} \frac{ax^2 + 2axh + ah^2 + bx + bh + c - ax^2 - bx - c}{h}$$
   $$= \lim_{h \to 0} \frac{h(2ax + ah + b)}{h} = 2ax + b$$
   Por lo tanto, $\frac{d}{dx}(ax^2 + bx + c) = 2ax + b$.
   > **Observación 68.** Si $a=1, b=0, c=0 \implies \frac{d}{dx}(x^2) = 2x$.

4. **Sea $f(x) = \frac{1}{x}$ ($x \neq 0$):**
   $$\lim_{h \to 0} \frac{\frac{1}{x+h} - \frac{1}{x}}{h} = \lim_{h \to 0} \frac{\frac{x - (x+h)}{x(x+h)}}{h} = \lim_{h \to 0} \frac{-h}{h x(x+h)} = \lim_{h \to 0} \frac{-1}{x(x+h)} = -\frac{1}{x^2}$$
   Por lo tanto, $\frac{d}{dx}\left(\frac{1}{x}\right) = -\frac{1}{x^2}$.

5. **Sea $f(x) = \sqrt{x}$ ($x > 0$):**
   $$\lim_{h \to 0} \frac{\sqrt{x+h} - \sqrt{x}}{h} = \lim_{h \to 0} \frac{(\sqrt{x+h} - \sqrt{x})(\sqrt{x+h} + \sqrt{x})}{h(\sqrt{x+h} + \sqrt{x})} = \lim_{h \to 0} \frac{x+h-x}{h(\sqrt{x+h} + \sqrt{x})} = \frac{1}{2\sqrt{x}}$$
   Por lo tanto, $\frac{d}{dx}(\sqrt{x}) = \frac{1}{2\sqrt{x}}$.

6. **Sea $f(x) = \sqrt[3]{x}$ ($x \neq 0$):**
   Racionalizando mediante el producto $a^3 - b^3 = (a-b)(a^2 + ab + b^2)$:
   $$\lim_{h \to 0} \frac{\sqrt[3]{x+h} - \sqrt[3]{x}}{h} = \lim_{h \to 0} \frac{(x+h) - x}{h\left(\sqrt[3]{(x+h)^2} + \sqrt[3]{x+h}\sqrt[3]{x} + \sqrt[3]{x^2}\right)} = \frac{1}{3\sqrt[3]{x^2}}$$
   Por lo tanto, $\frac{d}{dx}(\sqrt[3]{x}) = \frac{1}{3\sqrt[3]{x^2}}$ para $x \neq 0$. Si $x=0$, el límite tiende a $\infty$, por lo que no es derivable en $0$.

7. **Sea $f(x) = |x|$ ($x \neq 0$):**
   Calculamos $\lim_{h \to 0} \frac{|x+h| - |x|}{h}$:
   * Si $x > 0$, para $h$ suficientemente pequeño, $x+h > 0 \implies \lim_{h \to 0} \frac{x+h - x}{h} = 1$.
   * Si $x < 0$, para $h$ suficientemente pequeño, $x+h < 0 \implies \lim_{h \to 0} \frac{-(x+h) - (-x)}{h} = -1$.
   Por lo tanto:
   $$\frac{d}{dx}(|x|) = \begin{cases} 1, & \text{si } x > 0 \\ -1, & \text{si } x < 0 \end{cases} = \operatorname{sgn}(x)$$

8. **Sea $f(x) = \operatorname{Ent}(x) = \lfloor x \rfloor$ ($x \notin \mathbb{Z}$):**
   * Si $x \notin \mathbb{Z}$, existe $n \in \mathbb{Z}$ tal que $n < x < n+1$. Para $h$ suficientemente pequeño, $\lfloor x+h \rfloor = \lfloor x \rfloor = n$.
     $$\lim_{h \to 0} \frac{\lfloor x+h \rfloor - \lfloor x \rfloor}{h} = \lim_{h \to 0} \frac{n - n}{h} = 0$$
   * Si $x = n \in \mathbb{Z}$, evaluando límites laterales:
     $$\lim_{h \to 0^-} \frac{\lfloor n+h \rfloor - n}{h} = \lim_{h \to 0^-} \frac{(n-1) - n}{h} = +\infty$$
     $$\lim_{h \to 0^+} \frac{\lfloor n+h \rfloor - n}{h} = \lim_{h \to 0^+} \frac{n - n}{h} = 0$$
   Dado que los límites laterales difieren, no es derivable en $\mathbb{Z}$. En conclusión, $\frac{d}{dx}(\lfloor x \rfloor) = 0$ para $x \notin \mathbb{Z}$.

9. **Sea $f(x) = \sin x$:**
   $$\lim_{h \to 0} \frac{\sin(x+h) - \sin x}{h} = \lim_{h \to 0} \frac{\sin x \cos h + \sin h \cos x - \sin x}{h}$$
   $$= \sin x \lim_{h \to 0} \frac{\cos h - 1}{h} + \cos x \lim_{h \to 0} \frac{\sin h}{h}$$
   Usando $\lim_{h \to 0} \frac{1 - \cos h}{h} = 0$ y $\lim_{h \to 0} \frac{\sin h}{h} = 1$:
   $$= \sin x (0) + \cos x (1) = \cos x$$

10. **Sea $f(x) = \cos x$:**
    $$\lim_{h \to 0} \frac{\cos(x+h) - \cos x}{h} = \lim_{h \to 0} \frac{\cos x \cos h - \sin x \sin h - \cos x}{h}$$
    $$= -\cos x \lim_{h \to 0} \frac{1 - \cos h}{h} - \sin x \lim_{h \to 0} \frac{\sin h}{h} = -\sin x$$

11. **Sea $f(x) = \sinh x$:**
    $$\lim_{\Delta x \to 0} \frac{\sinh(x + \Delta x) - \sinh x}{\Delta x} = \lim_{\Delta x \to 0} \frac{\sinh x \cosh \Delta x + \sinh \Delta x \cosh x - \sinh x}{\Delta x}$$
    $$= \sinh x \lim_{\Delta x \to 0} \frac{\cosh \Delta x - 1}{\Delta x} + \cosh x \lim_{\Delta x \to 0} \frac{\sinh \Delta x}{\Delta x}$$
    Usando $\lim_{\Delta x \to 0} \frac{\cosh \Delta x - 1}{\Delta x} = 0$ y $\lim_{\Delta x \to 0} \frac{\sinh \Delta x}{\Delta x} = 1$:
    $$= \cosh x$$

12. **Sea $f(x) = \cosh x$:**
    $$\lim_{\Delta x \to 0} \frac{\cosh(x + \Delta x) - \cosh x}{\Delta x} = \lim_{\Delta x \to 0} \frac{\cosh x \cosh \Delta x + \sinh x \sinh \Delta x - \cosh x}{\Delta x}$$
    $$= \cosh x \lim_{\Delta x \to 0} \frac{\cosh \Delta x - 1}{\Delta x} + \sinh x \lim_{\Delta x \to 0} \frac{\sinh \Delta x}{\Delta x} = \sinh x$$

13. **Sea $f(x) = a^x$ ($a > 0, a \neq 1$):**
    $$\lim_{h \to 0} \frac{a^{x+h} - a^x}{h} = \lim_{h \to 0} \frac{a^x(a^h - 1)}{h}$$
    Usando la equivalencia $a^h - 1 \sim h \ln a$ cuando $h \to 0$:
    $$= a^x \lim_{h \to 0} \frac{h \ln a}{h} = a^x \ln a$$

14. **Sea $f(x) = \log_a x$ ($a > 0, a \neq 1, x > 0$):**
    $$\lim_{h \to 0} \frac{\log_a(x+h) - \log_a x}{h} = \lim_{h \to 0} \frac{\log_a\left(1 + \frac{h}{x}\right)}{h}$$
    Usando la equivalencia $\log_a\left(1 + \frac{h}{x}\right) \sim \frac{h}{x \ln a}$ cuando $\frac{h}{x} \to 0$:
    $$= \lim_{h \to 0} \frac{\frac{h}{x \ln a}}{h} = \frac{1}{x \ln a}$$

15. **Sea $f(x) = x^\alpha$ ($x > 0, \alpha \in \mathbb{R}$):**
    $$\lim_{h \to 0} \frac{(x+h)^\alpha - x^\alpha}{h} = \lim_{h \to 0} \frac{x^\alpha\left(1 + \frac{h}{x}\right)^\alpha - x^\alpha}{h} = x^\alpha \lim_{h \to 0} \frac{\left(1 + \frac{h}{x}\right)^\alpha - 1}{h}$$
    Usando la equivalencia $\left(1 + \frac{h}{x}\right)^\alpha - 1 \sim \frac{\alpha h}{x}$ cuando $\frac{h}{x} \to 0$:
    $$= x^\alpha \lim_{h \to 0} \frac{\frac{\alpha h}{x}}{h} = \alpha x^{\alpha-1}$$

#### PROBLEMA 2.7
Sea $f(x) = \frac{x^4}{4} - \frac{7x^3}{9} - \frac{11x^2}{3} + \frac{8x}{3}$. Hallar los puntos de la gráfica de $f$ en los cuales la recta tangente es horizontal.

#### PROBLEMA 2.8
Sea $f(x) = \frac{2x^3}{3} + \frac{x^2}{2} - x - 1$. Hallar los puntos de la gráfica de $f$ en los cuales la pendiente es:
i. $0$
ii. $-1$
iii. $5$

**Solución:**
El dominio de $f$ es $\mathbb{R}$. Los puntos $P(x_0, f(x_0))$ donde la pendiente es $m$ cumplen $f'(x_0) = m$.

* **Derivada de $f$:**
  $$f'(x) = \frac{d}{dx}\left(\frac{2x^3}{3} + \frac{x^2}{2} - x - 1\right) = 2x^2 + x - 1$$

* **Evaluación según la pendiente:**
  * **Para $m = 0$:**

  * **Para $m = -1$:**

  * **Para $m = 5$:**

#### PROBLEMA 2.9
Sea $f(x) = x^2 + ax + b$. Hallar valores de $a$ y $b$ tales que la recta $y = 2x$ sea tangente a la gráfica de $f$ en el punto $P(2,4)$.

**Solución:**
La recta $y = 2x$ tiene pendiente $m = 2$.
Para que la recta sea tangente a $f$ en $P(2,4)$:
1. $f$ pasa por $(2,4) \implies f(2) = 4$:
   $$f(2) = 2^2 + 2a + b = 4 \iff 4 + 2a + b = 4 \iff 2a + b = 0 \tag{2.6}$$

2. La derivada en $x = 2$ es la pendiente $m = 2$:
   $$f'(x) = 2x + a \implies f'(2) = 2(2) + a = 4 + a$$
   $$4 + a = 2 \implies a = -2$$

3. Sustituyendo $a = -2$ en $(2.6)$:
   $$2(-2) + b = 0 \implies b = 4$$

Por lo tanto, la función es $f(x) = x^2 - 2x + 4$ con $a = -2$ y $b = 4$.

#### PROBLEMA 2.10
Hallar valores de las constantes $a$, $b$ y $c$ para los cuales las gráficas de los dos polinomios $f(x) = x^2 + ax + b$ y $g(x) = x^3 - c$ se corten en el punto $P(1,2)$ y tengan la misma tangente en dicho punto.

**Solución:**
* Como se cortan en $P(1,2)$, tenemos $f(1) = 2$ y $g(1) = 2$:
  $$f(1) = 1 + a + b = 2 \implies a + b = 1 \tag{2.7}$$
  $$g(1) = 1 - c = 2 \implies c = -1$$

* Tienen la misma tangente en $P(1,2) \implies f'(1) = g'(1)$:
  * $f'(x) = 2x + a \implies f'(1) = 2 + a$
  * $g'(x) = 3x^2 \implies g'(1) = 3$
  * $2 + a = 3 \implies a = 1 \tag{2.8}$

* Sustituyendo $a = 1$ en $(2.7)$:
  $$1 + b = 1 \implies b = 0$$

Por lo tanto, los polinomios son $f(x) = x^2 + x$ y $g(x) = x^3 + 1$. La recta tangente común en $P(1,2)$ es $T: y = 3x - 1$.

#### PROBLEMA 2.11
Dibujar la gráfica del polinomio $f(x) = x - x^3$ en el intervalo cerrado $-2 \le x \le 2$. Hallar las constantes $m$ y $b$ de modo que la recta $y = mx + b$ sea tangente a la gráfica de $f$ en el punto $P(-1,0)$. Una segunda recta que pasa por el punto $P$ es también tangente a la gráfica de $f$ en el punto $Q(a,c)$. Determinar las coordenadas $a$ y $c$.

**Solución:**
* **Primera recta $T: y = mx + b$:**
  * Derivada de $f$: $f'(x) = 1 - 3x^2$
  * Pendiente $m = f'(-1) = 1 - 3(-1)^2 = -2$
  * Ecuación de $T$: $y - 0 = -2(x - (-1)) \iff y = -2x - 2$, de donde $b = -2$.

* **Segunda recta $L$ (pasa por $P(-1,0)$ y es tangente en $Q(a,c)$):**
  * Como $Q(a,c)$ está en la curva de $f$, $c = a - a^3$.
  * La pendiente de $L$ es $m_L = f'(a) = 1 - 3a^2$.
  * Ecuación de $L$:
    $$y - (a - a^3) = (1 - 3a^2)(x - a)$$
  * Como $L$ pasa por $P(-1,0)$:
    $$0 - (a - a^3) = (1 - 3a^2)(-1 - a) \iff (1 - 3a^2)(-1 - a) + (a - a^3) = 0$$
    $$(1 - 3a^2)(-1 - a) + a(1 - a)(1 + a) = 0 \iff (1 + a)[3a^2 - 1 + a(1 - a)] = 0$$
    $$(1 + a)(2a^2 + a - 1) = 0 \iff a = -1 \quad \lor \quad a = \frac{1}{2}$$

  * Si $a = -1 \implies c = 0$, que corresponde al propio punto $P(-1,0)$.
  * Si $a = \frac{1}{2} \implies c = \frac{1}{2} - \left(\frac{1}{2}\right)^3 = \frac{3}{8}$.

Por lo tanto, las coordenadas de $Q$ son $Q\left(\frac{1}{2}, \frac{3}{8}\right)$ y la ecuación de $L$ es $L: y - \frac{3}{8} = \frac{1}{4}\left(x - \frac{1}{2}\right) \iff y = \frac{x}{4} + \frac{1}{4}$.
