### TEOREMA 2.6
Sea $n \in \mathbb{N}$ y $a_n$ una constante real distinta de 0. La función polinomial:

$$f(x) = a_n x^n + a_{n-1} x^{n-1} + a_{n-2} x^{n-2} + a_{n-3} x^{n-3} + \dots + a_2 x^2 + a_1 x + a_0$$

es diferenciable en todo número real. Además,

$$f'(x) = n a_n x^{n-1} + (n-1) a_{n-1} x^{n-2} + (n-2) a_{n-2} x^{n-3} + (n-3) a_{n-3} x^{n-4} + \dots + 2 a_2 x + a_1$$

#### Corolario 2.6.1
Si $n \in \mathbb{N}$, entonces:

$$\frac{d}{dx}\left(x^n\right) = n x^{n-1}$$

#### Corolario 2.6.2
Si $n \in \mathbb{N}$ y $f(x) = x^{-n}$, entonces:

$$f'(x) = \frac{-n}{x^{n+1}}$$

### TEOREMA 2.8 (Derivada de la función logaritmo)
Sea $f(x) = \log_b x$, con $b > 0$ y $b \neq 1$, entonces $f$ es derivable para todo $x > 0$, además la derivada viene dada por la fórmula:

$$f'(x) = \frac{1}{x \ln b}$$

### TEOREMA 2.9 (Derivada de las funciones trigonométricas)

* **Derivada de la función seno:**
  $$\frac{d}{dx}(\sin x) = \cos x; \quad x \in \mathbb{R}$$

* **Derivada de la función coseno:**
  $$\frac{d}{dx}(\cos x) = -\sin x; \quad x \in \mathbb{R}$$

* **Derivada de la función tangente:**
  $$\frac{d}{dx}(\tan x) = \sec^2 x; \quad x \in \left((2n-1)\frac{\pi}{2}, (2n+1)\frac{\pi}{2}\right), \, n \in \mathbb{Z}$$

* **Derivada de la función cotangente:**
  $$\frac{d}{dx}(\cot x) = -\csc^2 x; \quad x \in (n\pi, (n+1)\pi), \, n \in \mathbb{Z}$$

* **Derivada de la función secante:**
  $$\frac{d}{dx}(\sec x) = \sec x \tan x; \quad x \in \left((2n-1)\frac{\pi}{2}, (2n+1)\frac{\pi}{2}\right), \, n \in \mathbb{Z}$$

* **Derivada de la función cosecante:**
  $$\frac{d}{dx}(\csc x) = -\csc x \cot x; \quad x \in (n\pi, (n+1)\pi), \, n \in \mathbb{Z}$$

### EJERCICIO 2.19
Probar los siguientes resultados:

1. $\frac{d}{dx}(\tan x) = \sec^2 x$
2. $\frac{d}{dx}(\cot x) = -\csc^2 x$
3. $\frac{d}{dx}(\sec x) = \sec x \tan x$
4. $\frac{d}{dx}(\csc x) = -\csc x \cot x$
5. $\frac{d}{dx}(\tanh x) = \text{sech}^2 x$
6. $\frac{d}{dx}(\coth x) = -\text{csch}^2 x$
7. $\frac{d}{dx}(\text{sech } x) = -\text{sech } x \tanh x$
8. $\frac{d}{dx}(\text{csch } x) = -\text{csch } x \coth x$

#### Solución
Probamos los resultados a partir del álgebra de derivadas y las derivadas conocidas de las funciones seno y coseno:

1. Probamos que $\frac{d}{dx}(\tan x) = \sec^2 x$, para todo $x \in X = \left(\frac{2\pi k - \pi}{2}, \frac{2\pi k + \pi}{2}\right)$:

   $$\frac{d}{dx}(\tan x) = \frac{d}{dx}\left(\frac{\sin x}{\cos x}\right) = \frac{\cos x \left[\frac{d}{dx}(\sin x)\right] - \sin x \left[\frac{d}{dx}(\cos x)\right]}{[\cos x]^2}$$

   $$= \frac{\cos x(\cos x) - \sin x(-\sin x)}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{1}{\cos^2 x} = \sec^2 x, \quad \cos x \neq 0$$

2. Probamos que $\frac{d}{dx}(\cot x) = -\csc^2 x$, para todo $x \in X = (\pi k, \pi k + \pi), \, k \in \mathbb{Z}$:

   $$\frac{d}{dx}(\cot x) = \frac{d}{dx}\left(\frac{\cos x}{\sin x}\right) = \frac{\sin x \left[\frac{d}{dx}(\cos x)\right] - \cos x \left[\frac{d}{dx}(\sin x)\right]}{[\sin x]^2}$$

   $$= \frac{\sin x(-\sin x) - \cos x(\cos x)}{\sin^2 x} = \frac{-\sin^2 x - \cos^2 x}{\sin^2 x} = \frac{-1}{\sin^2 x} = -\csc^2 x, \quad \sin x \neq 0$$

3. Probamos que $\frac{d}{dx}(\sec x) = \sec x \tan x$, para todo $x \in X = \left(\frac{2\pi k - \pi}{2}, \frac{2\pi k + \pi}{2}\right)$:

   $$\frac{d}{dx}(\sec x) = \frac{d}{dx}\left(\frac{1}{\cos x}\right) = \frac{\cos x \left[\frac{d}{dx}(1)\right] - (1)\left[\frac{d}{dx}(\cos x)\right]}{[\cos x]^2}$$

   $$= \frac{(0)\cos x - (-\sin x)}{\cos^2 x} = \frac{\sin x}{\cos^2 x} = \left(\frac{\sin x}{\cos x}\right)\left(\frac{1}{\cos x}\right) = \tan x \sec x, \quad \cos x \neq 0$$

4. Probamos que $\frac{d}{dx}(\csc x) = -\csc x \cot x$, para todo $x \in X = (\pi k, \pi k + \pi), \, k \in \mathbb{Z}$:

   $$\frac{d}{dx}(\csc x) = \frac{d}{dx}\left(\frac{1}{\sin x}\right) = \frac{\sin x \left[\frac{d}{dx}(1)\right] - (1)\left[\frac{d}{dx}(\sin x)\right]}{[\sin x]^2}$$

   $$= \frac{(0)\sin x - (\cos x)}{\sin^2 x} = \frac{-\cos x}{\sin^2 x} = -\left(\frac{\cos x}{\sin x}\right)\left(\frac{1}{\sin x}\right) = -\cot x \csc x, \quad \sin x \neq 0$$

5. Probamos que $\frac{d}{dx}(\tanh x) = \text{sech}^2 x$:

   $$\frac{d}{dx}(\tanh x) = \frac{d}{dx}\left(\frac{\sinh x}{\cosh x}\right) = \frac{\cosh x \left[\frac{d}{dx}(\sinh x)\right] - \sinh x \left[\frac{d}{dx}(\cosh x)\right]}{\cosh^2 x}$$

   $$= \frac{\cosh x \cosh x - \sinh x \sinh x}{\cosh^2 x} = \frac{\cosh^2 x - \sinh^2 x}{\cosh^2 x} = \frac{1}{\cosh^2 x} = \text{sech}^2 x$$

6. Probamos que $\frac{d}{dx}(\coth x) = -\text{csch}^2 x$:

   $$\frac{d}{dx}(\coth x) = \frac{d}{dx}\left(\frac{\cosh x}{\sinh x}\right) = \frac{\sinh x \left[\frac{d}{dx}(\cosh x)\right] - \cosh x \left[\frac{d}{dx}(\sinh x)\right]}{\sinh^2 x}$$

   $$= \frac{\sinh x \sinh x - \cosh x \cosh x}{\sinh^2 x} = \frac{\sinh^2 x - \cosh^2 x}{\sinh^2 x} = \frac{-1}{\sinh^2 x} = -\text{csch}^2 x$$

7. Probamos que $\frac{d}{dx}(\text{sech } x) = -\text{sech } x \tanh x$:

   $$\frac{d}{dx}(\text{sech } x) = \frac{d}{dx}\left(\frac{1}{\cosh x}\right) = \frac{\cosh x \left(\frac{d}{dx}(1)\right) - \left(\frac{d}{dx}(\cosh x)\right)}{\cosh^2 x}$$

   $$= \frac{0 - \sinh x}{\cosh^2 x} = -\frac{\sinh x}{\cosh^2 x} = -\left(\frac{\sinh x}{\cosh x}\right)\left(\frac{1}{\cosh x}\right) = -\tanh x \text{sech } x$$

8. Probamos que $\frac{d}{dx}(\text{csch } x) = -\text{csch } x \coth x$:

   $$\frac{d}{dx}(\text{csch } x) = \frac{d}{dx}\left(\frac{1}{\sinh x}\right) = \frac{\sinh x \left(\frac{d}{dx}(1)\right) - \left(\frac{d}{dx}(\sinh x)\right)}{\sinh^2 x}$$

   $$= \frac{0 - \cosh x}{\sinh^2 x} = -\frac{\cosh x}{\sinh^2 x} = -\left(\frac{\cosh x}{\sinh x}\right)\left(\frac{1}{\sinh x}\right) = -\coth x \text{csch } x$$

### EJERCICIO 2.20
Calcular la derivada de cada una de las funciones $f$ e indicar el campo de existencia de la misma.

1. $f(x) = x^3 + x^2 + x + 1$
2. $f(x) = a x^3 + b x^2 + c x + d$
3. $f(x) = 7 x^{13} + 13 x^{-7}$
4. $f(x) = \frac{\ln 3}{x} + e^2$
5. $f(x) = \frac{a}{x^2} + \frac{b}{x^3} + \frac{c}{x^4}$
6. $f(x) = \sqrt{x} + \sqrt[3]{x} + \sqrt[4]{x}$
7. $f(x) = \frac{3}{5} x^{5/3} + x^{-2} + \frac{2}{x}$
8. $f(x) = x^3 \sqrt[3]{x^2} + x^7 \sqrt[3]{x}$
9. $f(x) = x^{\sqrt{5}} - x^{-\sqrt{5}}$
10. $f(x) = \frac{x^2 - 5x + 6}{x^2 + x - 7}$
11. $f(x) = \frac{\sqrt{x}}{2 + \sqrt[3]{x^2}}$
12. $f(x) = 5x \cos x$
13. $f(x) = (x+1) \tan x$
14. $f(x) = x^2 \cot x + 2$
15. $f(x) = \frac{\sin x + \cos x}{\cos x - \sin x}$
16. $f(x) = \arctan x + x + \text{arccot } x$
17. $f(x) = x \arcsin x$
18. $f(x) = \frac{\arcsin x}{\arccos x}$
19. $f(x) = (x^2 - 7x + 8) e^x$
20. $f(x) = \sqrt{2}^x + \sqrt{5}^{-x}$
21. $f(x) = e^x \log_2 x$
22. $f(x) = \log_2 x \ln x \log_3 x$
23. $f(x) = e^x (a \sin x - b \cos x); \quad a, b \in \mathbb{R}$
24. $f(x) = \sinh x \cosh x$
25. $f(x) = \frac{\ln x}{\coth x}$
26. $f(x) = x \sin x + \cos x$

#### Solución:
Calculamos la derivada de $f$ usando las propiedades de la derivada y resultados conocidos.

1. $f(x) = x^3 + x^2 + x + 1$  
   La función está definida en $X = \mathbb{R}$.  
   $$\frac{d}{dx}(x^3 + x^2 + x + 1) = \frac{d}{dx}(x^3) + \frac{d}{dx}(x^2) + \frac{d}{dx}(x) + \frac{d}{dx}(1) = 3x^2 + 2x + 1; \quad x \in X$$

2. $f(x) = a x^3 + b x^2 + c x + d$  
   La función está definida en $X = \mathbb{R}$.  
   $$\frac{d}{dx}(a x^3 + b x^2 + c x + d) = 3a x^2 + 2b x + c; \quad x \in X$$

3. $f(x) = 7 x^{13} + 13 x^{-7}$  
   La función está definida en $X = \mathbb{R} - \{0\}$.  
   $$\frac{d}{dx}(7 x^{13} + 13 x^{-7}) = (7)(13)x^{12} + (13)(-7)x^{-8} = 91x^{12} - 91x^{-8} = 91(x^{12} - x^{-8}); \quad x \in X$$

4. $f(x) = \frac{\ln 3}{x} + e^2$  
   La función está definida en $X = \mathbb{R} - \{0\}$.  
   $$\frac{d}{dx}\left(\frac{\ln 3}{x} + e^2\right) = (\ln 3)\frac{d}{dx}\left(\frac{1}{x}\right) + \frac{d}{dx}(e^2) = -\frac{\ln 3}{x^2}; \quad x \in X$$

5. $f(x) = \frac{a}{x^2} + \frac{b}{x^3} + \frac{c}{x^4}$  
   La función está definida en $X = \mathbb{R} - \{0\}$.  
   $$\frac{d}{dx}(a x^{-2} + b x^{-3} + c x^{-4}) = -2a x^{-3} - 3b x^{-4} - 4c x^{-5} = -\frac{2a}{x^3} - \frac{3b}{x^4} - \frac{4c}{x^5}; \quad x \in X$$

6. $f(x) = \sqrt{x} + \sqrt[3]{x} + \sqrt[4]{x}$  
   La función está definida en $X = [0, +\infty)$. Es derivable en $X - \{0\}$.  
   $$\frac{d}{dx}(x^{1/2} + x^{1/3} + x^{1/4}) = \frac{1}{2}x^{-1/2} + \frac{1}{3}x^{-2/3} + \frac{1}{4}x^{-3/4} = \frac{1}{2\sqrt{x}} + \frac{1}{3\sqrt[3]{x^2}} + \frac{1}{4\sqrt[4]{x^3}}; \quad x \in X - \{0\}$$

7. $f(x) = \frac{3}{5} x^{5/3} + x^{-2} + \frac{2}{x}$  
   La función está definida en $X = \mathbb{R} - \{0\}$.  
   $$\frac{d}{dx}\left(\frac{3}{5} x^{5/3} + x^{-2} + \frac{2}{x}\right) = \left(\frac{3}{5}\right)\left(\frac{5}{3}\right)x^{2/3} - 2x^{-3} - \frac{2}{x^2} = \sqrt[3]{x^2} - \frac{2}{x^3} - \frac{2}{x^2}; \quad x \in X$$

8. $f(x) = x^3 \sqrt[3]{x^2} + x^7 \sqrt[3]{x} = x^{11/3} + x^{22/3}$  
   La función está definida en $X = \mathbb{R}$.  
   $$\frac{d}{dx}(x^{11/3} + x^{22/3}) = \frac{11}{3}x^{8/3} + \frac{22}{3}x^{19/3} = \frac{11}{3}x^2 \sqrt[3]{x^2} + \frac{22}{3}x^6 \sqrt[3]{x} = \frac{11x^2}{3}(\sqrt[3]{x^2} + 2x^4 \sqrt[3]{x}); \quad x \in X$$

9. $f(x) = x^{\sqrt{5}} - x^{-\sqrt{5}}$  
   La función está definida en $X = (0, +\infty)$.  
   $$\frac{d}{dx}(x^{\sqrt{5}} - x^{-\sqrt{5}}) = \sqrt{5}x^{\sqrt{5}-1} - (-\sqrt{5})x^{-\sqrt{5}-1} = \sqrt{5}\left(x^{\sqrt{5}-1} + \frac{1}{x^{\sqrt{5}+1}}\right) = \sqrt{5}\left(\frac{x^{\sqrt{5}} + x^{-\sqrt{5}}}{x}\right); \quad x \in X$$

10. $f(x) = \frac{x^2 - 5x + 6}{x^2 + x - 7}$  
    La función $f$ está definida en $X = \mathbb{R} - \left\{\frac{-1 + \sqrt{29}}{2}, \frac{-1 - \sqrt{29}}{2}\right\}$.  
    $$\frac{d}{dx}\left(\frac{x^2 - 5x + 6}{x^2 + x - 7}\right) = \frac{(x^2 + x - 7)\frac{d}{dx}(x^2 - 5x + 6) - (x^2 - 5x + 6)\frac{d}{dx}(x^2 + x - 7)}{(x^2 + x - 7)^2}$$  
    $$= \frac{(x^2 + x - 7)(2x - 5) - (x^2 - 5x + 6)(2x + 1)}{(x^2 + x - 7)^2} = \frac{6x^2 - 26x + 29}{(x^2 + x - 7)^2}; \quad x \in X$$

11. $f(x) = \frac{\sqrt{x}}{2 + \sqrt[3]{x^2}}$  
    La función está definida en $X = [0, +\infty)$.  
    $$\frac{d}{dx}\left(\frac{\sqrt{x}}{2 + \sqrt[3]{x^2}}\right) = \frac{(2 + \sqrt[3]{x^2})\left(\frac{1}{2\sqrt{x}}\right) - \sqrt{x}\left(\frac{2}{3\sqrt[3]{x}}\right)}{(2 + \sqrt[3]{x^2})^2} = \frac{6 - \sqrt[3]{x^2}}{6\sqrt{x}(2 + \sqrt[3]{x^2})^2}; \quad x \in X - \{0\}$$

12. $f(x) = 5x \cos x$  
    La función está definida en $X = \mathbb{R}$.  
    $$\frac{d}{dx}(5x \cos x) = 5\left(x \frac{d}{dx}(\cos x) + \cos x \frac{d}{dx}(x)\right) = 5(-x \sin x + \cos x); \quad x \in X$$

13. $f(x) = (x+1) \tan x$  
    La función está definida en $X = \left\{x \in \mathbb{R} \;\middle|\; x \neq \frac{\pi}{2}(2k+1), \, k \in \mathbb{Z}\right\}$.  
    $$\frac{d}{dx}((x+1)\tan x) = (x+1)\sec^2 x + \tan x; \quad x \in X$$

14. $f(x) = x^2 \cot x + 2$  
    La función está definida en $X = \{x \in \mathbb{R} \mid x \neq k\pi, \, k \in \mathbb{Z}\}$.  
    $$\frac{d}{dx}(x^2 \cot x + 2) = -x^2 \csc^2 x + 2x \cot x; \quad x \in X$$

15. $f(x) = \frac{\sin x + \cos x}{\cos x - \sin x}$  
    La función está definida en $X = \left\{x \in \mathbb{R} \;\middle|\; x \neq \frac{\pi}{4} + k\pi, \, k \in \mathbb{Z}\right\}$.  
    $$\frac{d}{dx}\left(\frac{\sin x + \cos x}{\cos x - \sin x}\right) = \frac{(\cos x - \sin x)(\cos x - \sin x) - (\sin x + \cos x)(-\sin x - \cos x)}{(\cos x - \sin x)^2}$$  
    $$= \frac{(\cos x - \sin x)^2 + (\sin x + \cos x)^2}{(\cos x - \sin x)^2} = \frac{2}{(\cos x - \sin x)^2}; \quad x \in X$$

16. $f(x) = \arctan x + x + \text{arccot } x$  
    La función está definida en $X = \mathbb{R}$.  
    $$\frac{d}{dx}(\arctan x + x + \text{arccot } x) = \frac{1}{1+x^2} + 1 + \frac{-1}{1+x^2} = 1; \quad x \in X$$

17. $f(x) = x \arcsin x$  
    La función está definida en $X = [-1, 1]$.  
    $$\frac{d}{dx}(x \arcsin x) = x\left(\frac{1}{\sqrt{1-x^2}}\right) + \arcsin x = \frac{x}{\sqrt{1-x^2}} + \arcsin x; \quad x \in (-1, 1)$$

18. $f(x) = \frac{\arcsin x}{\arccos x}$  
    La función está definida en $X = [-1, 1)$.  
    $$\frac{d}{dx}\left(\frac{\arcsin x}{\arccos x}\right) = \frac{\arccos x \left(\frac{1}{\sqrt{1-x^2}}\right) - \arcsin x \left(\frac{-1}{\sqrt{1-x^2}}\right)}{(\arccos x)^2} = \frac{\arccos x + \arcsin x}{\sqrt{1-x^2}(\arccos x)^2} = \frac{\pi}{2\sqrt{1-x^2}(\arccos x)^2}; \quad x \in (-1, 1)$$

19. $f(x) = (x^2 - 7x + 8) e^x$  
    La función está definida en $X = \mathbb{R}$.  
    $$\frac{d}{dx}((x^2 - 7x + 8)e^x) = (x^2 - 7x + 8)e^x + e^x(2x - 7) = e^x(x^2 - 5x + 1); \quad x \in X$$

20. $f(x) = \sqrt{2}^x + \sqrt{5}^{-x}$  
    La función $f$ está definida en $X = \mathbb{R}$.  
    $$\frac{d}{dx}(\sqrt{2}^x + \sqrt{5}^{-x}) = \sqrt{2}^x \ln\sqrt{2} - \sqrt{5}^{-x} \ln\sqrt{5}; \quad x \in X$$

21. $f(x) = e^x \log_2 x$  
    La función está definida en $X = (0, +\infty)$.  
    $$\frac{d}{dx}(e^x \log_2 x) = e^x\left(\frac{1}{x \ln 2}\right) + e^x \log_2 x = e^x \left(\frac{1}{x \ln 2} + \log_2 x\right); \quad x \in X$$

22. $f(x) = \log_2 x \ln x \log_3 x$  
    La función está definida en $X = (0, +\infty)$.  
    $$\frac{d}{dx}(\log_2 x \ln x \log_3 x) = \frac{1}{x}\left(\frac{\log_2 x \ln x}{\ln 3} + \log_2 x \log_3 x + \frac{\ln x \log_3 x}{\ln 2}\right); \quad x \in X$$

23. $f(x) = e^x(a \sin x - b \cos x); \quad a, b \in \mathbb{R}$  
    La función $f$ está definida en $X = \mathbb{R}$.  
    $$\frac{d}{dx}(e^x(a \sin x - b \cos x)) = e^x(a \cos x + b \sin x) + (a \sin x - b \cos x)e^x = e^x[(a+b)\sin x + (a-b)\cos x]; \quad x \in X$$

24. $f(x) = \sinh x \cosh x$  
    La función está definida en $X = \mathbb{R}$.  
    $$\frac{d}{dx}(\sinh x \cosh x) = \sinh x \sinh x + \cosh x \cosh x = \sinh^2 x + \cosh^2 x; \quad x \in X$$

25. $f(x) = \frac{\ln x}{\coth x}$

    $$\frac{d}{dx}\left(\frac{\ln x}{\coth x}\right) = \frac{\coth x \left(\frac{1}{x}\right) - \ln x (-\text{csch}^2 x)}{\coth^2 x} = \frac{1}{x \coth x} + \frac{\ln x}{\cosh^2 x}; \quad x \in X$$

    La función está definida en $X = \mathbb{R}$.  
    $$f'(x) = (x)' \sin x + x(\sin x)' + (\cos x)' = \sin x + x \cos x - \sin x = x \cos x; \quad x \in X$$

## 2.3. DERIVADAS DE ORDEN SUPERIOR

Sea $f$ una función real definida en $X \subset \mathbb{R}$. Se definen la segunda derivada, tercera derivada y la $n$-ésima derivada de $f$ ($n \in \mathbb{N}$) de la siguiente forma:

* **Segunda derivada de $f$:**
  $$f''(x) = \frac{d}{dx}(f'(x))$$
  Símbolos: $\frac{d^2 f(x)}{dx^2}$, $f^{(2)}(x)$, $f_2(x)$.

* **Tercera derivada de $f$:**
  $$f'''(x) = \frac{d}{dx}(f''(x))$$
  Símbolos: $\frac{d^3 f(x)}{dx^3}$, $f^{(3)}(x)$, $f_3(x)$.

* **$n$-ésima derivada de $f$:**
  $$f^{(n)}(x) = \frac{d}{dx}(f^{(n-1)}(x)); \quad n \in \mathbb{N}$$
  Símbolos: $\frac{d^n f(x)}{dx^n}$, $f_n(x)$.

> **Observación 59:** Si $n = 0$, se entiende que $f^{(0)}$ representa la función $f$. El símbolo $f^{(n)}$ se usa para la derivada de orden $n$ cuando $n \ge 4$.

## 2.4. INCREMENTOS Y DIFERENCIALES

### DEFINICIÓN 2.4.1 (Incrementos)
Sea $f$ una función de la variable $x$ definida en el intervalo abierto $I = (x_0 - \gamma, x_0 + \gamma)$, con $\gamma > 0$. Se definen los incrementos:

* **Incremento de $f$ en $x_0$:**
  $$\Delta f_{x_0} = f(x_0 + \Delta x) - f(x_0)$$
  donde $\Delta x$ es un número real tal que $x_0 + \Delta x \in I$. Si $y = f(x)$, escribimos $\Delta y_{x_0}$.
* **Incremento de $x$:** El incremento de la variable $x$ se define como $\Delta x$.

---

### DEFINICIÓN 2.4.2 (Diferenciales)
Sea $f$ una función definida en $I = (x_0 - \gamma, x_0 + \gamma)$ con $\gamma > 0$. Si el incremento de $f$ en $x_0$ puede expresarse en la forma:

$$\Delta f_{x_0} = A(x_0)\Delta x + \alpha(\Delta x)\Delta x$$

donde $A$ es una función que no depende de $\Delta x$ y $\alpha$ es una función tal que $\lim_{\Delta x \to 0} \alpha(\Delta x) = 0$, entonces se define el **diferencial de $f$ en $x_0$** como:

$$df(x_0) = A(x_0)\Delta x$$

Se define el diferencial de la variable $x$ como el incremento $\Delta x$, constante, denotado por $dx$.

---

### TEOREMA 2.13
Sea $f$ una función definida en $I = (x_0 - \gamma, x_0 + \gamma)$, con $\gamma > 0$. $f$ es diferenciable en $x_0$ si y solo si tiene derivada en dicho punto. Además:

$$df_{x_0} = f'(x_0)\Delta x$$

> **Observación 60:** Si $f$ es diferenciable en $x$, $df(x) = f'(x)dx, \quad \forall x \in I$.

> **Observación 61:** Para $\Delta x \to 0$:
> $$f(x_0 + \Delta x) \approx f(x_0) + f'(x_0)\Delta x$$

---

### TEOREMA 2.14 (Propiedades del diferencial)
Sean $f$ y $g$ funciones derivables y $\alpha, \beta \in \mathbb{R}$:

* **Propiedad homogénea:** $d(\alpha f) = \alpha df$
* **Propiedad aditiva:** $d(f+g) = df + dg$
* **Propiedad lineal:** $d(\alpha f + \beta g) = \alpha df + \beta dg$
* **Propiedad del producto:** $d(fg) = f \cdot dg + g \cdot df$
* **Propiedad del cociente:** $d\left(\frac{f}{g}\right) = \frac{g \cdot df - f \cdot dg}{g^2}$

---

### DEFINICIÓN 2.4.3 (Diferenciales de orden superior)
Se llama diferencial de segundo orden al diferencial del diferencial de $f$: $d^2 f = d(df)$.

> **Observación 62:** $d^2 f = d(df) = d(f'(x)\Delta x) = f''(x)\Delta x^2$.
