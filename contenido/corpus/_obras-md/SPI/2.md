# CAPÍTULO 2: DISTINTAS CLASES DE NÚMEROS

En el capítulo 1 hemos usado la palabra «número» con poca precisión a pesar de habernos preocupado tanto por las propiedades básicas de los números. Podría resultar oportuno distinguir distintas clases de números.

Los números más sencillos son los «números de contar»:

$$1, 2, 3, \dots$$

La importancia de este conjunto de números se sugiere por su símbolo $\mathbb{N}$ (de números naturales). Una breve revisión de $P_1-P_{12}$ sugiere que nuestras propiedades básicas de los números no aplican para $\mathbb{N}$; por ejemplo, $P_2$ y $P_3$ no tienen sentido en $\mathbb{N}$. Desde este punto de vista, el sistema $\mathbb{N}$ presenta ciertas deficiencias. Sin embargo, $\mathbb{N}$ ofrece suficiente relevancia para que se dediquen algunos comentarios antes de abordar conjuntos más amplios.

La propiedad fundamental de $\mathbb{N}$ se relaciona con el principio de **inducción matemática**. Supóngase que $P(x)$ representa que la propiedad $P$ se cumple para el número $x$. Entonces el principio de inducción matemática sugiere que $P(x)$ es verdadero para todos los números naturales $x$ siempre que:

1. $P(1)$ sea verdadero.
2. Si $P(k)$ es verdadero, se infiere que $P(k+1)$ también lo es.

Nótese que la condición (2) se limita a considerar la validez de $P(k+1)$ bajo el supuesto de que $P(k)$ sea verdadero. Esto parece suficiente para explorar la validez de $P(x)$ para todo $x$ si se satisface la condición (1). En efecto, si $P(1)$ es verdadero, se deduce que $P(2)$ es verdadero (aplicando (2) al caso particular $k=1$). Dado que $P(2)$ es verdadero, se evalúa que $P(3)$ es verdadero (aplicando (2) al caso particular $k=2$). Se deduce que todo número puede ser alcanzado eventualmente mediante una serie de etapas, de modo que $P(k)$ resulte válido para los números $k$.

Una ilustración corriente para analizar la inducción matemática considera una fila de personas:

$$\text{persona n.º 1}, \quad \text{persona n.º 2}, \quad \text{persona n.º 3}, \quad \dots$$

Si cada persona recibe la instrucción de compartir cualquier información recibida a la persona siguiente en orden numérico, y se entrega un mensaje a la persona n.º 1, se infiere que cada persona eventualmente recibirá el mensaje. Si $P(x)$ representa la afirmación de que la persona número $x$ recibe el mensaje, entonces las instrucciones dadas implican que la condición (2) se cumple, mientras que entregar el mensaje a la persona número 1 satisface (1).

El siguiente ejemplo representa una aplicación de la inducción matemática. Existe una fórmula representativa que expresa la suma de los $n$ primeros números:

$$1 + \dots + n = \frac{n(n+1)}{2}$$

Para explorar la validez de esta fórmula, se evalúa primero para $n=1$. Supóngase que para algún entero $k$ se tiene:

$$1 + \dots + k = \frac{k(k+1)}{2}$$

Entonces:

$$1 + \dots + k + (k+1) = \frac{k(k+1)}{2} + k + 1 = \frac{k(k+1) + 2k + 2}{2} = \frac{k^2 + 3k + 2}{2} = \frac{(k+1)(k+2)}{2}$$

de manera que la fórmula también aplica para $k+1$. Por el principio de inducción, esto sugiere que la fórmula es válida para los números naturales $n$. Aunque la demostración por inducción suele ser directa, el proceso mediante el cual la fórmula se concibe no siempre es obvio. Los problemas 4 y 5 sugieren cómo pueden deducirse fórmulas de este tipo.

El principio de inducción matemática puede formularse de manera equivalente sin recurrir al término «propiedades». Una formulación alternativa expresa que si $A$ es una colección (o conjunto) de números naturales y:

1. $1$ pertenece a $A$,
2. $k+1$ pertenece a $A$ siempre que $k$ pertenece a $A$,

entonces $A$ constituye el conjunto de los números naturales. Esta consideración sustituye la formulación anterior; aquí se evalúa el conjunto $A$ de los números naturales $x$ que satisfacen $P(x)$. Por ejemplo, supóngase que $A$ es el conjunto de los números naturales $n$ para los cuales se cumple:

$$1 + \dots + n = \frac{n(n+1)}{2}$$

La revisión anterior sugiere que $A$ contiene a $1$ y que $k+1$ pertenece a $A$ si $k$ pertenece a $A$. Se infiere que $A$ es el conjunto de todos los números naturales, lo cual indica que la fórmula aplica para los números naturales $n$.

Existe otra formulación del principio de inducción matemática. Si $A$ es una colección cualquiera de números naturales, se suele examinar si en $A$ existe un elemento menor que todos los demás. Esta consideración puede requerir precisiones. Un conjunto particular de números naturales es la colección $A$ que no contiene ningún número natural, denominado **conjunto vacío**, que se designa por $\emptyset$. El conjunto vacío $\emptyset$ no posee elemento mínimo al carecer de elementos. Sin embargo, se sugiere que si $A$ es un conjunto no vacío de números naturales, entonces $A$ posee un elemento mínimo. Esta afirmación, conocida como **principio de buena ordenación**, puede explorarse a partir del principio de inducción.

Supóngase que el conjunto $A$ carece de elemento mínimo. Sea $B$ el conjunto de los números naturales $n$ tales que $1, \dots, n$ no pertenecen a $A$. Se observa que $1$ está en $B$ (pues si $1$ estuviese en $A$, entonces $A$ tendría a $1$ como elemento mínimo). Además, si $1, \dots, k$ no están en $A$, se infiere que $k+1$ no está en $A$ (de lo contrario $k+1$ sería el elemento mínimo de $A$), de modo que $1, \dots, k+1$ no pertenecen a $A$. Esto sugiere que si $k$ está en $B$, entonces $k+1$ está en $B$. Se deduce que todo número $n$ está en $B$, es decir, los números $1, \dots, n$ no están en $A$ para cualquier número natural. Así pues, $A = \emptyset$.

Es posible explorar el principio de inducción a partir del principio de buena ordenación (problema 10). Cualquiera de estos principios puede considerarse como un postulado básico sobre los números naturales.

Otra variante de la inducción requiere ser mencionada. Ocurre a veces que para evaluar $P(k+1)$ conviene suponer no solo $P(k)$, sino también $P(l)$ para todos los números naturales $l \le k$. En este caso se recurre al **principio de inducción completa**. Si $A$ es un conjunto de números naturales y:

1. $1$ está en $A$,
2. $k+1$ está en $A$ si $1, \dots, k$ están en $A$,

entonces $A$ representa el conjunto de todos los números naturales.

Aunque el principio de inducción completa puede sugerir mayor alcance que el principio de inducción ordinario, se deduce como una consecuencia de este último (problema 11). Aplicaciones de este principio se plantean en los problemas 7, 17, 20 y 22.

En relación con las demostraciones por inducción se encuentran las **definiciones recursivas**. Por ejemplo, el número $n!$ (factorial de $n$) se define preliminarmente como el producto de los números naturales menores o iguales a $n$:

$$n! = 1 \cdot 2 \cdot \dots \cdot (n-1) \cdot n$$

Esto puede expresarse recursivamente mediante:

1. $1! = 1$
2. $n! = n \cdot (n-1)!$

Esta forma hace explícita la relación entre $n!$ y $(n-1)!$, estructura adecuada para argumentos por inducción. El problema 23 revisa aspectos de esta definición.

Otra notación conveniente que se empleará con frecuencia involucra la suma. En lugar de escribir:

$$a_1 + \dots + a_n$$

se emplea la letra griega $\Sigma$ (sigma mayúscula) para denotar:

$$\sum_{i=1}^{n} a_i$$

Designa la suma de los números obtenidos haciendo $i = 1, 2, \dots, n$. Así:

$$\sum_{i=1}^{n} i = 1 + 2 + \dots + n = \frac{n(n+1)}{2}$$

Obsérvese que la variable $i$ no altera el valor de la expresión y puede sustituirse por otros símbolos:

$$\sum_{j=1}^{n} j = \frac{n(n+1)}{2}$$

$$\sum_{j=1}^{i} j = \frac{i(i+1)}{2}$$

$$\sum_{n=1}^{j} n = \frac{j(j+1)}{2}$$

Para definir $\sum_{i=1}^{n} a_i$ se sugiere una estructura recursiva:

1. $\sum_{i=1}^{1} a_i = a_1$
2. $\sum_{i=1}^{n} a_i = \left( \sum_{i=1}^{n-1} a_i \right) + a_n$

En la práctica se utilizan variaciones de este simbolismo. La expresión:

$$\sum_{\substack{i=1 \\ i \neq 4}}^{n} a_i$$

representa:

$$a_1 + a_2 + a_3 + a_5 + a_6 + \dots + a_n$$

o, con mayor precisión:

$$\sum_{i=1}^{3} a_i + \sum_{i=5}^{n} a_i$$

Las limitaciones de los números naturales pueden considerarse parcialmente resueltas extendiendo el sistema al conjunto de los enteros:

$$\dots, -2, -1, 0, 1, 2, \dots$$

Este conjunto se designa por $\mathbb{Z}$ (del alemán *Zahl*). De las propiedades $P_1-P_{12}$, únicamente $P_7$ deja de cumplirse en $\mathbb{Z}$.

Un sistema más amplio se obtiene considerando cocientes $\frac{m}{n}$ de enteros con $n \neq 0$. Estos elementos reciben el nombre de **números racionales**, y su conjunto se designa por $\mathbb{Q}$ (del inglés *quotient*). En este sistema se satisfacen las propiedades $P_1-P_{12}$.

Existe un conjunto más amplio para el cual son válidas las propiedades $P_1-P_{12}$: el conjunto de los **números reales**, designado por $\mathbb{R}$. Los números reales incluyen los racionales y los números irracionales, representables mediante decimales infinitos no periódicos; $\pi$ y $\sqrt{2}$ constituyen ejemplos representativos.

La irracionalidad de $\sqrt{2}$ puede examinarse a partir de ciertas observaciones sobre $\mathbb{N}$. Todo número natural $n$ es par (de la forma $2k$) o impar (de la forma $2k+1$) para algún entero $k$. Al elevar al cuadrado:

$$(2k)^2 = 4k^2 = 2(2k^2)$$

$$(2k+1)^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$$

Se infiere que los números pares poseen cuadrados pares y los impares cuadrados impares. Recíprocamente, si $n^2$ es par, $n$ es par; si $n^2$ es impar, $n$ es impar.

Para evaluar la irracionalidad de $\sqrt{2}$, supóngase que fuese racional, es decir, que existieran números naturales $p$ y $q$ sin divisores comunes tales que:

$$\left(\frac{p}{q}\right)^2 = 2$$

De lo anterior se deduce:

$$p^2 = 2q^2$$

Esto sugiere que $p^2$ es par, por lo que $p$ debe ser par ($p = 2k$). Reemplazando:

$$p^2 = 4k^2 = 2q^2 \implies 2k^2 = q^2$$

Se deduce que $q^2$ es par y, por lo tanto, $q$ es par. Esto indica que tanto $p$ como $q$ son pares, lo cual entra en contradicción con la hipótesis de que no comparten divisores comunes. La contradicción sugiere que no existe un número racional $x$ tal que $x^2 = 2$.

### 3. Coeficientes Binomiales y Teorema del Binomio

Si $0 \le k \le n$, se define el coeficiente binomial $\binom{n}{k}$ por:

$$\binom{n}{k} = \frac{n!}{k!(n-k)!} = \frac{n(n-1)\dots(n-k+1)}{k!}, \quad \text{si } k \neq 0, n$$

$$\binom{n}{0} = \binom{n}{n} = 1$$

**(a)** Demostrar que:

$$\binom{n+1}{k} = \binom{n}{k-1} + \binom{n}{k}$$

Esta relación da lugar a la configuración conocida como el **triángulo de Pascal**.

**(b)** Utilizar la parte (a) para demostrar por inducción que $\binom{n}{k}$ es un número natural.

**(c)** Proporcionar otra explicación considerando que $\binom{n}{k}$ representa el número de subconjuntos de $k$ elementos elegidos entre $1, \dots, n$.

**(d)** Demostrar el **teorema del binomio**: Si $a$ y $b$ son números reales, entonces:

$$(a+b)^n = a^n + \binom{n}{1}a^{n-1}b + \binom{n}{2}a^{n-2}b^2 + \dots + \binom{n}{n-1}ab^{n-1} + b^n = \sum_{j=0}^{n} \binom{n}{j} a^{n-j} b^j$$

**(e)** Demostrar que:

(i) $$\sum_{j=0}^{n} \binom{n}{j} = \binom{n}{0} + \dots + \binom{n}{n} = 2^n$$

(ii) $$\sum_{j=0}^{n} (-1)^j \binom{n}{j} = \binom{n}{0} - \binom{n}{1} + \dots \pm \binom{n}{n} = 0$$

(iii) $$\sum_{l \text{ impar}} \binom{n}{l} = \binom{n}{1} + \binom{n}{3} + \dots = 2^{n-1}$$

(iv) $$\sum_{l \text{ par}} \binom{n}{l} = \binom{n}{0} + \binom{n}{2} + \dots = 2^{n-1}$$

### 6. Método de diferencias para sumas de potencias

A partir de la identidad:

$$(k+1)^3 - k^3 = 3k^2 + 3k + 1$$

sumando para $k=1, \dots, n$, se obtiene:

$$(n+1)^3 - 1 = 3 \sum_{k=1}^{n} k^2 + 3 \sum_{k=1}^{n} k + n$$

Aplicar este procedimiento para obtener:

(i) $$\sum_{k=1}^{n} k^3 = 1^3 + \dots + n^3$$

(ii) $$\sum_{k=1}^{n} k^4 = 1^4 + \dots + n^4$$

(iii) $$\frac{1}{1 \cdot 2} + \frac{1}{2 \cdot 3} + \dots + \frac{1}{n(n+1)}$$

(iv) $$\frac{3}{1^2 \cdot 2^2} + \frac{5}{2^2 \cdot 3^2} + \dots + \frac{2n+1}{n^2 (n+1)^2}$$
