# Capítulo: Límites

## TEOREMA 2

Si $\lim_{x \to a} f(x) = l$ y $\lim_{x \to a} g(x) = m$, entonces:

1. $\lim_{x \to a} (f + g)(x) = l + m$
2. $\lim_{x \to a} (f \cdot g)(x) = l \cdot m$

Además, si $m \neq 0$, entonces:

3. $\lim_{x \to a} \left(\frac{1}{g}\right)(x) = \frac{1}{m}$

---

### DEMOSTRACIÓN

La hipótesis significa que para todo $\epsilon > 0$ existen $\delta_1, \delta_2 > 0$ tales que, para todo $x$:

- si $0 < |x - a| < \delta_1$, entonces $|f(x) - l| < \epsilon$,
- y si $0 < |x - a| < \delta_2$, entonces $|g(x) - m| < \epsilon$.

Esto significa (ya que, después de todo, $\frac{\epsilon}{2}$ es también un número positivo) que existen $\delta_1, \delta_2 > 0$ tales que, para todo $x$:

- si $0 < |x - a| < \delta_1$, entonces $|f(x) - l| < \frac{\epsilon}{2}$,
- y si $0 < |x - a| < \delta_2$, entonces $|g(x) - m| < \frac{\epsilon}{2}$.

Sea ahora $\delta = \min(\delta_1, \delta_2)$. Si $0 < |x - a| < \delta$, entonces $0 < |x - a| < \delta_1$ y $0 < |x - a| < \delta_2$ se cumplen las dos, de modo que es a la vez:

$$|f(x) - l| < \frac{\epsilon}{2} \quad \text{y} \quad |g(x) - m| < \frac{\epsilon}{2}$$

Pero según la parte (1) del lema, esto implica que:

$$|(f + g)(x) - (l + m)| < \epsilon$$

Esto demuestra **(1)**.

---

Para demostrar **(2)** procedemos de la misma manera, después de consultar la parte (2) del lema. Si $\epsilon > 0$, existen $\delta_1, \delta_2 > 0$ tales que, para todo $x$:

- si $0 < |x - a| < \delta_1$, entonces $|f(x) - l| < \min\left(1, \frac{\epsilon}{2(|m| + 1)}\right)$
- y si $0 < |x - a| < \delta_2$, entonces $|g(x) - m| < \frac{\epsilon}{2(|l| + 1)}$

Pongamos de nuevo $\delta = \min(\delta_1, \delta_2)$. Si $0 < |x - a| < \delta$, entonces:

$$|f(x) - l| < \min\left(1, \frac{\epsilon}{2(|m| + 1)}\right) \quad \text{y} \quad |g(x) - m| < \frac{\epsilon}{2(|l| + 1)}$$

Así pues, según el lema, $|(f \cdot g)(x) - l \cdot m| < \epsilon$, y esto demuestra **(2)**.

---

Finalmente, si $\epsilon > 0$, existe un $\delta > 0$ tal que, para todo $x$:

- si $0 < |x - a| < \delta$, entonces $|g(x) - m| < \min\left(\frac{|m|}{2}, \frac{\epsilon|m|^2}{2}\right)$

Pero según la parte (3) del lema, esto significa, en primer lugar que $g(x) \neq 0$, de modo que $\left(\frac{1}{g}\right)(x)$ tiene sentido, y en segundo lugar que:

$$\left|\left(\frac{1}{g}\right)(x) - \frac{1}{m}\right| < \epsilon$$

Esto demuestra **(3)**.

---

Aplicando el Teorema 2 se demuestran, trivialmente, resultados del tipo:

$$\lim_{x \to a} \frac{x^3 + 7x^5}{x^2 + 1} = \frac{a^3 + 7a^5}{a^2 + 1}$$

sin pasar por el proceso laborioso de encontrar un $\delta$ para un $\epsilon$ dado. Debemos empezar con:

$$\lim_{x \to a} 7 = 7$$
$$\lim_{x \to a} 1 = 1$$
$$\lim_{x \to a} x = a$$

pero éstos son fáciles de demostrar directamente. Sin embargo, si queremos encontrar el $\delta$, la demostración del Teorema 2 equivale a unas instrucciones para hacer esto. Tomando un ejemplo más sencillo, supóngase que queremos encontrar un $\delta$ tal que, para todo $x$:

$$\text{si } 0 < |x - a| < \delta, \text{ entonces } |x^2 + x - (a^2 + a)| < \epsilon$$

Consultando la demostración del Teorema 2(1), se ve que debemos encontrar primero $\delta_1, \delta_2 > 0$ tales que, para todo $x$:

$$\text{si } 0 < |x - a| < \delta_1, \text{ entonces } |x^2 - a^2| < \frac{\epsilon}{2}$$
$$\text{y si } 0 < |x - a| < \delta_2, \text{ entonces } |x - a| < \frac{\epsilon}{2}$$

Esto lo sabemos hacer ya por las demostraciones que hemos dado de que $\lim_{x \to a} x^2 = a^2$ y $\lim_{x \to a} x = a$. Así pues, podemos tomar:

$$\delta_1 = \min\left(1, \frac{\epsilon/2}{2(|a| + 1)}\right)$$
$$\delta_2 = \frac{\epsilon}{2}$$
$$\delta = \min(\delta_1, \delta_2) = \min\left(\min\left(1, \frac{\epsilon/2}{2(|a| + 1)}\right), \frac{\epsilon}{2}\right)$$

Si es $a \neq 0$, se puede aplicar el mismo método para encontrar un $\delta > 0$ tal que, para todo $x$:

$$\text{si } 0 < |x - a| < \delta \text{ entonces } \left|\frac{1}{x^2} - \frac{1}{a^2}\right| < \epsilon$$

La demostración del Teorema 2(3) hace ver que se seguirá la segunda condición si encontramos un $\delta > 0$ tal que, para todo $x$:

$$\text{si } 0 < |x - a| < \delta, \text{ entonces } |x^2 - a^2| < \min\left(\frac{|a|^2}{2}, \frac{\epsilon|a|^4}{2}\right)$$

Así pues, podemos tomar:

$$\delta = \min\left(1, \frac{\min\left(\frac{|a|^2}{2}, \frac{\epsilon|a|^4}{2}\right)}{2(|a| + 1)}\right)$$

Estas complicadas expresiones para $\delta$ pueden, naturalmente, simplificarse una vez deducidas.

---

Hay un detalle técnico en la demostración del Teorema 2 que merece comentario. Para que esté definido $\lim_{x \to a} f(x)$ no es necesario, como sabemos, que $f$ esté definido en $a$, ni es necesario tampoco que $f$ esté definido en todos los puntos $x \neq a$. Sin embargo, debe haber algún $\delta > 0$ tal que $f(x)$ esté definida para los $x$ que satisfacen $0 < |x - a| < \delta$; de otro modo la cláusula «si $0 < |x - a| < \delta$, entonces $|f(x) - l| < \epsilon$» no tendría sentido en absoluto, ya que el símbolo $f(x)$ dejaría de tener sentido para algunos $x$. Si $f$ y $g$ son dos funciones bien definidas, es fácil ver que también están bien definidas $f + g$ y $f \cdot g$. Sin embargo, la cosa no está tan clara para $1/g$, puesto que $1/g$ no está definida para $x$ cuando es $g(x) = 0$. De todos modos, este hecho ha quedado ya establecido en la demostración del Teorema 2(3).

Hay veces en que vendría bien hablar del límite a que tiende $f$ en $a$, aun cuando no exista ningún $\delta > 0$ tal que $f(x)$ esté definida para los $x$ que satisfacen $0 < |x - a| < \delta$. Se puede tratar, por ejemplo, de distinguir el comportamiento de las dos funciones de la **Figura 16 (página 130 del libro)**, aunque no estén definidas para números menores que $a$. Para la función de la **Figura 16(a)** escribimos:

$$\lim_{x \to a^+} f(x) = l \quad \text{o} \quad \lim_{x \downarrow a} f(x) = l$$

(Los símbolos de la izquierda se leen: el límite de $f(x)$ cuando $x$ tiende hacia $a$ desde arriba.) Estos «límites desde arriba» están evidentemente en estrecha relación con los límites ordinarios, y la definición es muy parecida: $\lim_{x \to a^+} f(x) = l$ significa que para todo $\epsilon > 0$ existe un $\delta > 0$ tal que, para todo $x$:

$$\text{si } 0 < x - a < \delta, \text{ entonces } |f(x) - l| < \epsilon$$

> *Nota sobre las gráficas:*  
> - **Figura 16(a) y 16(b)**: Véase la **página 130 del libro** para apreciar el comportamiento de la función $f(x)$ cuando $x$ tiende a $a$ desde arriba (límite lateral por la derecha y oscilaciones).

(La condición $0 < x - a < \delta$ es equivalente a $0 < |x - a| < \delta$ y $x > a$.)

Los «límites desde abajo» (**Figura 17, página 130 del libro**) se definen de manera análoga:

$$\lim_{x \to a^-} f(x) = l \quad \text{o} \quad \lim_{x \uparrow a} f(x) = l$$

significa que para todo $\epsilon > 0$ existe un $\delta > 0$ tal que, para todo $x$:

$$\text{si } 0 < a - x < \delta, \text{ entonces } |f(x) - l| < \epsilon$$

> *Nota sobre las gráficas:*  
> - **Figura 17**: Véase la **página 130 del libro** para observar la representación gráfica de un límite desde abajo (límite lateral por la izquierda).

Es posible considerar límites desde abajo y desde arriba aunque la función esté definida tanto para valores mayores como para valores menores que $a$. Así, para la función $f$ de la **Figura 13 (mencionada en el texto)**, se tiene:

$$\lim_{x \to 0^+} f(x) = 1 \quad \text{y} \quad \lim_{x \to 0^-} f(x) = -1$$

Constituye un ejercicio fácil (problema 29) demostrar que $\lim_{x \to a} f(x)$ existe si y sólo si los dos límites $\lim_{x \to a^+} f(x)$ y $\lim_{x \to a^-} f(x)$ existen y son iguales.

Lo mismo que las definiciones de límite desde arriba y desde abajo introducidas informalmente en el texto, existen otras modificaciones del concepto de límite que resultan útiles. En el capítulo 4 se dijo que si $x$ es grande, entonces $\sin(1/x)$ está cerca de 0. Este resultado se escribe por lo general:

$$\lim_{x \to \infty} \sin\left(\frac{1}{x}\right) = 0$$

El símbolo $\lim_{x \to \infty} f(x)$ se lee «límite de $f(x)$ cuando $x$ tiende hacia $\infty$», o «cuando $x$ se hace infinito», y un límite de la forma $\lim_{x \to \infty} f(x)$ suele llamarse límite en el infinito.

La **Figura 18 (página 130 del libro)** ilustra una situación general donde es $\lim_{x \to \infty} f(x) = l$. Formalmente, $\lim_{x \to \infty} f(x) = l$ significa que para todo $\epsilon > 0$ existe un número $N$ tan grande, que, para todo $x$:

$$\text{si } x > N, \text{ entonces } |f(x) - l| < \epsilon$$

> *Nota sobre las gráficas:*  
> - **Figura 18**: Véase la **página 130 del libro** para apreciar el comportamiento asintótico de una función cuando $x \to \infty$.

Debe quedar clara la analogía con la definición de límites ordinarios: mientras la condición $0 < |x - a| < \delta$ expresa el hecho de que $x$ está cerca de $a$, la condición $x > N$ expresa el hecho de que $x$ es grande.

Hemos dedicado tan poco tiempo a los límites desde arriba y desde abajo, así como a los límites en el infinito, porque la idea general que se oculta tras las definiciones debe quedar clara una vez que se ha comprendido la definición de límites ordinarios (que son, con mucho, los más importantes). Sobre estas definiciones se dan muchos ejercicios en los problemas, los cuales contienen también límites de otros tipos que son útiles en ocasiones.

**41.** Una vez ya en la imprenta el manuscrito de la primera edición de este libro, se me ocurrió una manera mucho más sencilla de demostrar que $\lim_{x \to a} x^2 = a^2$, y $\lim_{x \to a} x^3 = a^3$, sin pasar por todos los pasos de la página 83. Supongamos que queremos demostrar que $\lim_{x \to a} x^2 = a^2$, siendo $a > 0$. Dado $\epsilon > 0$ hacemos simplemente que $\delta$ sea el mínimo de $\sqrt{a^2 + \epsilon} - a$ y $a - \sqrt{a^2 - \epsilon}$ (**Figura 19, página 139 del libro**); entonces $|x - a| < \delta$ implica que $\sqrt{a^2 - \epsilon} \le x < \sqrt{a^2 + \epsilon}$ de modo que $a^2 - \epsilon < x^2 < a^2 + \epsilon$, o $|x^2 - a^2| < \epsilon$. Por fortuna no llegué a tiempo para introducir estos cambios, puesto que esta «demostración» es totalmente falsa. ¿Dónde se encuentra el fallo?
