**Teorema · Regla de diferenciación para la suma.** Si $h(x) = f(x) + g(x)$ y $f'(x)$ y
$g'(x)$ existen, entonces $h'(x) = f'(x) + g'(x)$; esto es,

$$D_x [f(x) + g(x)] = D_x f(x) + D_x g(x)$$

**Demostración.**

$$h'(x) = \lim_{\Delta x \to 0} \frac{[f(x+\Delta x) + g(x+\Delta x)] - [f(x) + g(x)]}{\Delta x}$$

$$= \lim_{\Delta x \to 0} \frac{f(x+\Delta x) - f(x)}{\Delta x} + \lim_{\Delta x \to 0} \frac{g(x+\Delta x) - g(x)}{\Delta x} = f'(x) + g'(x)$$

> **La derivada de la suma de dos funciones es la suma de sus derivadas, si esas derivadas
> existen.**

El resultado se extiende por inducción a **cualquier número finito de funciones**, y con
eso la derivada de un polinomio sale de inmediato.

**Ejemplo.** Si $f(x) = 7x^4 - 2x^3 + 8x + 5$, entonces

$$f'(x) = D_x(7x^4) + D_x(-2x^3) + D_x(8x) + D_x(5) = 28x^3 - 6x^2 + 8$$
