**Teorema · Regla para la potencia.** Si $f(x) = x^n$, donde $n$ es un entero positivo,
entonces $f'(x) = n x^{n-1}$; esto es,

$$D_x(x^n) = n x^{n-1}$$

**Demostración.** Se apoya en el desarrollo del binomio
$(a + b)^n = a^n + na^{n-1}b + \frac{n(n-1)}{2}a^{n-2}b^2 + \dots + nab^{n-1} + b^n$.

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} = \lim_{h \to 0} \frac{(x+h)^n - x^n}{h}$$

$$= \lim_{h \to 0} \frac{x^n + n x^{n-1}h + \frac{n(n-1)}{2}x^{n-2}h^2 + \dots + n x h^{n-1} + h^n - x^n}{h}$$

$$= \lim_{h \to 0} \frac{h \left[ n x^{n-1} + \frac{n(n-1)}{2}x^{n-2}h + \dots + n x h^{n-2} + h^{n-1} \right]}{h}$$

Dentro de los corchetes, todos los términos excepto el primero tienen a $h$ como factor,
de modo que cada uno de ellos tiene límite cero cuando $h$ se aproxima a cero. Por lo
tanto, $f'(x) = n x^{n-1}$.

Como ejemplos:
$$D_x(x^3) = 3x^2, \quad D_x(x^9) = 9x^8, \quad D_x(x^{100}) = 100x^{99}$$
