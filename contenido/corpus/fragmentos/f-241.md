**De dónde sale $\lim_{t \to 0} \operatorname{sen} t = 0$.** Supóngase $t > 0$ y
considérese la circunferencia unitaria. Comparando longitudes se obtiene

$$0 < |\overline{BP}| < |\overline{AP}| < \text{arco}(AP)$$

Como $|\overline{BP}| = \operatorname{sen} t$ y $\text{arco}(AP) = t$, resulta
$0 < \operatorname{sen} t < t$. Si $t < 0$, entonces $t < \operatorname{sen} t < 0$. **Por
el teorema del emparedado** se concluye que $\lim_{t \to 0} \operatorname{sen} t = 0$.

De ahí se obtiene también el coseno:

$$\lim_{t \to 0} \cos t = \lim_{t \to 0} \sqrt{1 - \operatorname{sen}^2 t} = \sqrt{1 - 0^2} = 1$$

y con la identidad $\operatorname{sen}(c + h) = \operatorname{sen} c \cos h + \cos c
\operatorname{sen} h$, haciendo $h = t - c$, se llega al caso general.
