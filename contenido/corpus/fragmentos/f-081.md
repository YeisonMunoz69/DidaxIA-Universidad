**A cada regla de derivación le corresponde una regla de diferenciación.** Se obtiene de
la primera «multiplicándola» por $dx$.

| Regla de derivación | Regla de diferenciación |
| :--- | :--- |
| $\frac{dk}{dx} = 0$ | $dk = 0$ |
| $\frac{d(ku)}{dx} = k\frac{du}{dx}$ | $d(ku) = k \, du$ |
| $\frac{d(u+v)}{dx} = \frac{du}{dx} + \frac{dv}{dx}$ | $d(u+v) = du + dv$ |
| $\frac{d(uv)}{dx} = u\frac{dv}{dx} + v\frac{du}{dx}$ | $d(uv) = u \, dv + v \, du$ |
| $\frac{d(u/v)}{dx} = \frac{v(du/dx) - u(dv/dx)}{v^2}$ | $d\left(\frac{u}{v}\right) = \frac{v \, du - u \, dv}{v^2}$ |
| $\frac{d(u^n)}{dx} = n u^{n-1} \frac{du}{dx}$ | $d(u^n) = n u^{n-1}\, du$ |

La correspondencia es exacta y no hay reglas nuevas que aprender: es la misma lista
escrita en la otra notación.
