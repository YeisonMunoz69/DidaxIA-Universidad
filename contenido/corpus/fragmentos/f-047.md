**Ejemplo · Dónde la tangente es horizontal.** Determine todos los puntos en la gráfica
de $y = \sin^2 x$ donde la recta tangente es horizontal.

**Solución.** La recta tangente es horizontal cuando la derivada es igual a cero. Para
obtener la derivada de $\sin^2 x$ se utiliza la regla del producto:

$$\frac{d}{dx} \sin^2 x = \frac{d}{dx} (\sin x \sin x) = \sin x \cos x + \sin x \cos x = 2 \sin x \cos x$$

El producto de $\sin x$ y $\cos x$ es igual a cero cuando $\sin x$ o $\cos x$ son
iguales a cero; esto es, en $x = 0, \pm\pi/2, \pm\pi, \pm 3\pi/2, \dots$
