**Lo que ya se puede derivar juntando los teoremas: cualquier polinomio.** Si

$$f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_2 x^2 + a_1 x + a_0$$

entonces

$$f'(x) = n a_n x^{n-1} + (n-1) a_{n-1} x^{n-2} + \dots + 2 a_2 x + a_1$$

y se puede seguir:

$$f''(x) = n(n-1) a_n x^{n-2} + (n-1)(n-2) a_{n-1} x^{n-3} + \dots + 2 a_2$$

**El proceso se agota, y se agota de forma predecible.** Cada derivación reduce en una
unidad la potencia más alta de $x$ y elimina un coeficiente más. La última derivada
interesante es

$$f^{(n)}(x) = n!\, a_n$$

y para $k > n$ se tiene $f^{(k)}(x) = 0$.

**Un polinomio de grado $n$ tiene exactamente $n$ derivadas no nulas**, y la última es una
constante que solo depende del coeficiente principal. Es el ejemplo más limpio de que
derivar repetidamente no es repetir lo mismo: es descender por una escalera con final.
