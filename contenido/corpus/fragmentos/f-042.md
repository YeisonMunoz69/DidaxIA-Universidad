**Ejemplo · Regla del cociente con funciones trigonométricas.** Determine
$\frac{d}{dx} \left[ \frac{1 + \sin x}{\cos x} \right]$.

**Solución.** Para este problema es necesaria la regla del cociente.

$$\frac{d}{dx} \left[ \frac{1 + \sin x}{\cos x} \right] = \frac{\cos x \frac{d}{dx}(1 + \sin x) - (1 + \sin x) \frac{d}{dx}(\cos x)}{\cos^2 x}$$

$$= \frac{\cos x (\cos x) - (1 + \sin x)(-\sin x)}{\cos^2 x} = \frac{\cos^2 x + \sin x + \sin^2 x}{\cos^2 x} = \frac{1 + \sin x}{\cos^2 x}$$
