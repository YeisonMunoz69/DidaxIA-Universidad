**Error absoluto y error relativo.** Es un problema común en la ciencia: un investigador
mide una variable $x$ y obtiene $x_0$ con un posible error de tamaño $\pm \Delta x$.
Después usa $x_0$ para calcular un valor $y_0$ de una magnitud $y$ que depende de $x$. El
valor $y_0$ queda contaminado por el error en $x$, y el procedimiento estándar para
estimar cuánto es **usar diferenciales**.

La cantidad $\Delta V$ —o, aproximada, $dV$— se denomina **error absoluto**. Otra medida
es el **error relativo**, que se obtiene dividiendo el error absoluto entre el valor
total:

$$\frac{\Delta V}{V} \approx \frac{dV}{V}$$

Con frecuencia el error relativo se expresa en porcentaje. Las dos medidas dicen cosas
distintas: el absoluto lleva unidades y el relativo no, y por eso el relativo es el que
permite comparar mediciones de magnitudes diferentes.
