**Ejemplo · Tercera derivada de una combinación trigonométrica.** Calcule

$$\frac{d^3}{dx^3} (2 \operatorname{sen} x + 3 \cos x - x^3)$$

**Solución.** Se deriva tres veces seguidas, cuidando el signo en cada paso:

$$\frac{d}{dx} = 2 \cos x - 3 \operatorname{sen} x - 3x^2$$

$$\frac{d^2}{dx^2} = -2 \operatorname{sen} x - 3 \cos x - 6x$$

$$\frac{d^3}{dx^3} = -2 \cos x + 3 \operatorname{sen} x - 6$$

**El signo cambia cada vez que se deriva un coseno**, y con cuatro derivaciones se vuelve
al punto de partida: seno y coseno tienen un ciclo de periodo cuatro. El término
polinómico, en cambio, se agota.
