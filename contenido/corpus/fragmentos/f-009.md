**Ejemplo · Derivada por definición de un polinomio.** Si $f(x) = x^3 + 7x$, encuentre
$f'(x)$.

**Solución.**

$$f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h} = \lim_{h \to 0} \frac{[(x + h)^3 + 7(x + h)] - [x^3 + 7x]}{h}$$

$$= \lim_{h \to 0} \frac{3x^2h + 3xh^2 + h^3 + 7h}{h} = \lim_{h \to 0} (3x^2 + 3xh + h^2 + 7) = 3x^2 + 7$$
