**Teorema · Regla de diferenciación de potencias, con exponente entero positivo.** Si $n$
es un entero positivo y $f(x) = x^n$, entonces $f'(x) = n x^{n-1}$; esto es,
$D_x(x^n) = n x^{n-1}$.

**Demostración.** Partiendo de la definición y aplicando el teorema del binomio a
$(x+\Delta x)^n$:

$$f'(x) = \lim_{\Delta x \to 0} \frac{\left[ x^n + n x^{n-1} \Delta x + \frac{n(n-1)}{2!} x^{n-2} (\Delta x)^2 + \dots + (\Delta x)^n \right] - x^n}{\Delta x}$$

Los dos $x^n$ se cancelan, y dividiendo numerador y denominador entre $\Delta x$:

$$f'(x) = \lim_{\Delta x \to 0} \left[ n x^{n-1} + \frac{n(n-1)}{2!} x^{n-2} \Delta x + \dots + (\Delta x)^{n-1} \right]$$

**Cada término excepto el primero conserva un factor $\Delta x$**, así que todos tienden a
cero. Queda $f'(x) = n x^{n-1}$.

Por ejemplo, si $f(x) = x^8$, entonces $f'(x) = 8x^7$.
