**Teorema · Regla para la suma.** Si $f$ y $g$ son funciones derivables, entonces
$(f+g)'(x) = f'(x) + g'(x)$; esto es,

$$D_x [f(x) + g(x)] = D_x f(x) + D_x g(x)$$

En palabras: la derivada de una suma es la suma de las derivadas.

**Demostración.** Sea $F(x) = f(x) + g(x)$. Entonces

$$F'(x) = \lim_{h \to 0} \frac{[f(x+h) + g(x+h)] - [f(x) + g(x)]}{h}$$

$$= \lim_{h \to 0} \left[ \frac{f(x+h) - f(x)}{h} + \frac{g(x+h) - g(x)}{h} \right]$$

$$= \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} + \lim_{h \to 0} \frac{g(x+h) - g(x)}{h} = f'(x) + g'(x)$$

El penúltimo paso está justificado por el teorema principal de límites, parte 4.
