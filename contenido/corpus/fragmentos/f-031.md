**Ejemplo · Aplicar la regla del producto y comprobar el resultado.** Encuentre la
derivada de $(3x^2 - 5)(2x^4 - x)$ mediante la regla del producto, y verifique la
respuesta resolviendo el problema de otra forma.

**Solución.**

$$D_x [(3x^2 - 5)(2x^4 - x)] = (3x^2 - 5) D_x (2x^4 - x) + (2x^4 - x) D_x (3x^2 - 5)$$

$$= (3x^2 - 5)(8x^3 - 1) + (2x^4 - x)(6x)$$

$$= 24x^5 - 3x^2 - 40x^3 + 5 + 12x^5 - 6x^2 = 36x^5 - 40x^3 - 9x^2 + 5$$

Para verificar, primero se multiplica y luego se toma la derivada:

$$(3x^2 - 5)(2x^4 - x) = 6x^6 - 10x^4 - 3x^3 + 5x$$

$$D_x [(3x^2 - 5)(2x^4 - x)] = D_x(6x^6) - D_x(10x^4) - D_x(3x^3) + D_x(5x) = 36x^5 - 40x^3 - 9x^2 + 5$$
